刷题顺序六大模板填空/判断选择题解答题易错点

一、这套题怎么刷最划算

老师说考试题比练习题还简单，那你不要先去啃难概念。最稳的路线是：先把这套题刷熟，再回头用板书 HTML 查公式。 你要追求的不是“完全理解概率论”，而是看到题能立刻反应：这是全概率、这是密度函数、这是极大似然、这是 U/t 检验。

第1优先解答题 L4/L7/L8/L9
连续密度、极大似然、假设检验、置信区间。最像期末大题。
第2优先解答题 L1/L2/L6
全概率贝叶斯、二维离散表。步骤固定，容易拿过程分。
第3优先填空 + 选择
小题很多是送分公式：正态、卡方、条件概率、CLT。
刷法：第一遍看答案学套路；第二遍盖住答案自己写；第三遍只看题目，30秒内说出“用哪个公式”。考试更简单的话，这个方法性价比最高。

二、六大必背答题模板

全概率 + 贝叶斯
先设 A=目标事件，Bi=来源分类；P(A)=ΣP(Bi)P(A|Bi)；P(Bk|A)=P(Bk)P(A|Bk)/P(A)。
连续密度题
先用 ∫f(x)dx=1 求参数；再分段写 F(x)；最后用 F(b)-F(a) 或直接积分求概率。
二维离散表
边缘分布=行/列求和；期望=值×概率求和；函数分布=按格子列举。
极大似然估计
L(θ)=样本概率相乘；lnL；求导=0；解 θ；必要时说明二阶导<0。
置信区间
σ已知用 z：x̄±zα/2σ/√n；σ未知用 t：x̄±tα/2(n-1)s/√n。
假设检验
H0/H1 → 选统计量 → 找临界值 → 算统计量 → 比较 → 写题目化结论。

三、填空/判断题整理

这些题主要是公式识别。不要花太多时间推导，直接记“触发词 - 公式”。

F1必会事件表示
题目
设 A、B、C 为三个事件。用集合运算表示：①至少有一个发生；②恰有两个发生；③三个都发生。
答案：① A∪B∪C；② (A∩B∩C̄)∪(A∩B̄∩C)∪(Ā∩B∩C)；③ A∩B∩C。
理解/注释：“至少一个”就是并集；“恰有两个”要分三种情况：AB发生C不发生、AC发生B不发生、BC发生A不发生；“都发生”就是交集。考试看到“至少、至多、恰有”先翻译成集合语言。
F2秒杀加法公式
题目
已知 P(A)=0.8，P(B)=0.4，P(A∩B)=0.3，求 P(A∪B)。
答案：P(A∪B)=0.8+0.4-0.3=0.9。
理解/注释：两个事件加法公式：P(A∪B)=P(A)+P(B)-P(A∩B)。交集被重复算了一次，所以要减掉。
F3秒杀加法公式反求交集
题目
已知 P(A∪B)=0.8，P(A)=0.5，P(B)=0.6，求 P(A∩B)。
答案：P(A∩B)=0.5+0.6-0.8=0.3。
理解/注释：把加法公式变形：P(A∩B)=P(A)+P(B)-P(A∪B)。
F4必会独立事件
题目
设 A、B 相互独立，P(A)=0.8，P(B)=0.4，求 P(A∩B̄)。
答案：P(A∩B̄)=P(A)P(B̄)=0.8×(1-0.4)=0.48。
理解/注释：独立事件的补事件也独立。P(B̄)=1-P(B)=0.6。
F5必会条件概率
题目
已知 P(A|B)=0.8，P(A)=0.5，P(B)=0.6，求 P(A∩B) 与 P(B|A)。
答案：P(A∩B)=P(A|B)P(B)=0.8×0.6=0.48；P(B|A)=P(A∩B)/P(A)=0.48/0.5=0.96。
理解/注释：条件概率公式：P(A|B)=P(A∩B)/P(B)。先求交集，再反过来求 P(B|A)。
F6秒杀离散分布列
题目
随机变量 X 的分布列为 X=-2,0,1,2；概率分别为 0.2,0.15,c,0.3。求 c。
答案：c=1-0.2-0.15-0.3=0.35。
理解/注释：离散分布列所有概率相加必须等于 1。
F7常考指数分布
题目
设 X 的密度函数为 f(x)=3e^{-3x}, x>0；x≤0 时为0。求 E(X)、Var(X)。
答案：X~Exp(3)，所以 E(X)=1/3，Var(X)=1/9。
理解/注释：指数分布参数为 λ 时：E(X)=1/λ，Var(X)=1/λ²。本题 λ=3。
F8必背标准正态分布
题目
设 X~N(0,1)，Φ(x) 为标准正态分布函数，写出 Φ(x)+Φ(-x) 与 Φ(0)。
答案：Φ(x)+Φ(-x)=1；Φ(0)=1/2。
理解/注释：标准正态分布关于 0 对称。左边面积和右边面积互补。
F9常考正态线性组合
题目
设 X~N(-2,4)，Y~N(1,6)，且 X、Y 独立。求 2X-3Y 的分布。
答案：2X-3Y ~ N(-7,70)。
理解/注释：均值：2×(-2)-3×1=-7；方差：2²×4+(-3)²×6=16+54=70。独立正态的线性组合仍为正态。
F10常考独立离散变量
题目
设 X 与 Y 独立，且同分布：P(X=0)=0.5，P(X=1)=0.5。求 P{XY=0}。
答案：P{XY=0}=1-P(X=1,Y=1)=1-0.5×0.5=0.75。
理解/注释：XY=0 的反面是 XY≠0。因为 X、Y 只能取0或1，所以反面就是 X=1 且 Y=1。
F11理解相关系数
题目
若两个随机变量满足完全负线性关系，例如 Y=a-bX 且 b>0，求 Corr(X,Y)。
答案：Corr(X,Y)=-1。
理解/注释：相关系数等于 -1 表示完全负相关。板书/练习中这类题的关键是看出 Y 可以由 X 线性表示，且斜率为负。
F12常考矩估计
题目
设 P(X=0)=θ，P(X=1)=1-θ，0<θ<1。根据样本均值 X̄，求 θ 的矩估计。
答案：E(X)=1-θ，令 X̄=1-θ，得 θ̂=1-X̄。
理解/注释：矩估计套路：先写总体均值 E(X)，再令 E(X)=样本均值 X̄，最后解参数。
F13常考已知方差的置信区间
题目
设 X~N(μ,σ²)，已知 σ=2.1，n=16，样本均值 x̄=12。求 μ 的 0.95 置信区间。已知 z0.025=1.96。
答案：置信区间为 [10.971,13.029]。
理解/注释：已知 σ 用正态 U 区间：x̄±z_{α/2}·σ/√n = 12±1.96×2.1/4 = 12±1.029。
F14必背卡方分布
题目
设 X~N(0,1)，Y~N(0,1)，且 X、Y 独立。写出 X²+Y² 与 (X+Y)²/2 的分布。
答案：X²+Y² ~ χ²(2)；(X+Y)²/2 ~ χ²(1)。
理解/注释：独立标准正态平方和服从卡方分布，自由度等于平方项个数。因为 X+Y~N(0,2)，所以 (X+Y)/√2~N(0,1)，其平方服从 χ²(1)。

四、选择题整理

选择题不用写长步骤，但你要知道为什么选它。下面按“题目核心 - 答案 - 秒杀理由”整理。

C1假设检验两类错误
题目核心
第一类错误与第二类错误的定义。
答案：A
秒杀理由：第一类错误：H0 实际为真，却拒绝 H0。第二类错误：H0 实际为假，却接受/未拒绝 H0。这个几乎是概念送分题。
C2抽样分布
题目核心
设 X~N(μ,σ²)，样本容量 n=36，样本方差 S²，判断 (35S²)/σ² 的卡方自由度。
答案：A
秒杀理由：正态总体中：(n-1)S²/σ² ~ χ²(n-1)。n=36，所以自由度 35。
C3中心极限定理
题目核心
Xi 独立同分布，服从参数 λ 的泊松分布，判断标准化形式。
答案：B
秒杀理由：泊松分布 E(X)=λ，Var(X)=λ。和的均值 nλ，方差 nλ，所以标准化为 (ΣXi-nλ)/√(nλ)。
C4无偏估计与有效性
题目核心
X~N(μ,1)，X1,X2,X3 为样本，比较多个 μ 的无偏估计量，选最有效的。
答案：D
秒杀理由：线性估计量 ΣaiXi 若 Σai=1，则无偏。方差为 Σai²。方差越小越有效。四个选项中 D 的权重平均方差最小：1/3。
C5概率为零不等于空集
题目核心
设事件 A、B 满足 P(AB)=0，判断正确说法。
答案：C
秒杀理由：因为 A=(A∩B)∪(A∩B̄)，且两部分互斥，所以 P(A)=P(A∩B)+P(A∩B̄)=P(A∩B̄)。注意 P(AB)=0 不代表 AB 一定是空集。

五、解答题：标准答案 + 套路

这一部分才是你最应该刷的。大题要练“格式”，不是只看懂结果。

L1高频模板全概率公式 + 贝叶斯公式
题目
某产品来自 I、II、III 三类设备，比例分别为 30%、40%、30%；次品率分别为 1%、0.5%、2%。随机抽取一件，求次品概率；若已知为次品，求其来自 II 类设备的概率。
标准结果：P(A)=0.3×0.01+0.4×0.005+0.3×0.02=0.011。P(B2|A)=0.4×0.005/0.011=2/11≈0.182。
考试步骤：
  1. 设 A=抽到次品，B1/B2/B3=来自 I/II/III 类设备。
  2. 先用全概率公式求 P(A)。
  3. 再用贝叶斯公式求 P(B2|A)。
我的提醒：这类题考试最爱考。看到“来自几台机器/几家工厂/几批产品”，基本就是全概率 + 贝叶斯。
L2高频模板全概率公式 + 贝叶斯公式
题目
三台机床 B1、B2、B3 分别生产 30%、45%、25% 的零件，次品率分别为 2%、3%、2%。求随机零件为次品的概率；已知次品，求来自 B2 的概率。
标准结果：P(A)=0.3×0.02+0.45×0.03+0.25×0.02=0.0245。P(B2|A)=0.45×0.03/0.0245≈0.551。
考试步骤：
  1. 设 A=次品。
  2. 全概率：P(A)=ΣP(Bi)P(A|Bi)。
  3. 贝叶斯：P(B2|A)=P(B2)P(A|B2)/P(A)。
我的提醒：和第1题完全同型。刷到这类题不要怕，机械套公式就能拿分。
L3常考中心极限定理
题目
某考试通过率为 0.65，有 200 名学生参加。写出独立同分布中心极限定理，并用它近似计算至少 120 人通过的概率。
标准结果：设 X~B(200,0.65)，np=130，np(1-p)=45.5。P(X≥120)≈P((X-130)/√45.5 ≥ (120-130)/√45.5)=P(Z≥-1.482)=Φ(1.482)≈0.9306。
考试步骤：
  1. 把每个学生是否通过记为 Xi，Xi~B(1,0.65)。
  2. 总通过人数 X=ΣXi~B(200,0.65)。
  3. 二项分布用正态近似：均值 np，方差 np(1-p)。
  4. 标准化后查标准正态表。
我的提醒：PDF 最后一行疑似把 0.9306 写成了 0.9036；按前面 z=1.482 和正态表，结果应约为 0.9306。若老师课堂强调某个数，考试按老师口径写；但数学计算是 0.9306。
L4高频模板连续型随机变量：密度 + 分布函数
题目
设 f(x)=b(2-x), 0≤x≤2；其他为0。求 b、分布函数 F(x)，并计算 P(0.5<X<1.5)。
标准结果：b=1/2。F(x)=0(x<0)；F(x)=x-x²/4(0≤x≤2)；F(x)=1(x>2)。P(0.5<X<1.5)=F(1.5)-F(0.5)=1/2。
考试步骤：
  1. 密度函数第一步永远是积分等于1。
  2. 求 F(x) 时必须分段：x<0，0≤x≤2，x>2。
  3. 区间概率用 F(b)-F(a)。
我的提醒：这是连续型随机变量最标准的大题模板，几乎要背下来。
L5常考二维连续型：边缘密度 + 独立性 + 区域积分
题目
设联合密度 f(x,y)=1，0<x<1,0<y<1；其他为0。证明 X、Y 独立，并求 P(X<Y)。
标准结果：fX(x)=1(0<x<1)，fY(y)=1(0<y<1)，且 f(x,y)=fX(x)fY(y)，所以独立。P(X<Y)=∫₀¹∫₀ʸ 1 dxdy=1/2。
考试步骤：
  1. 先对 y 积分求 fX(x)，对 x 积分求 fY(y)。
  2. 比较 f(x,y) 与 fX(x)fY(y)。
  3. P(X<Y) 是单位正方形中 y>x 的三角形面积。
我的提醒：如果密度是均匀的，区域积分常常可以直接看面积。
L6高频模板二维离散型：边缘分布 + 期望 + 函数分布
题目
给定二维离散分布表，X,Y 取 1,2,3。求 X、Y 的边缘分布；求 E(X)、E(Y)；求 Z=max{X,Y} 的分布。
标准结果：X 的边缘分布：P(1)=1/3，P(2)=1/2，P(3)=1/6。Y 同样。E(X)=E(Y)=11/6。Z 的分布：P(Z=1)=1/12，P(Z=2)=7/12，P(Z=3)=1/3。
考试步骤：
  1. 边缘分布：固定 X 的值，把对应列加起来；固定 Y 的值，把对应行加起来。
  2. 期望：E(X)=ΣxP(X=x)。
  3. Z=max{X,Y}：分别列出最大值等于1、2、3的格子。
我的提醒：二维离散表不要慌，就是“行列求和”。函数分布靠列格子。
L7高频模板极大似然估计
题目
设 P(X=0)=θ²，P(X=1)=2θ(1-θ)，P(X=2)=(1-θ)²，0<θ<1。样本为 (0,1,2,1)，求 θ 的极大似然估计。
标准结果：L(θ)=θ²·[2θ(1-θ)]·(1-θ)²·[2θ(1-θ)]=4θ⁴(1-θ)⁴。lnL=ln4+4lnθ+4ln(1-θ)。求导得 4/θ-4/(1-θ)=0，所以 θ̂=1/2。
考试步骤：
  1. 把样本每个观测值对应的概率乘起来。
  2. 取对数，把乘法变加法。
  3. 求导=0，解 θ。
  4. 二阶导小于0，说明是最大值。
我的提醒：极大似然一定要写 L(θ)，然后 lnL、求导、解参数。步骤写全就有分。
L8高频模板假设检验：σ²已知，用 U 检验
题目
产品指标 X~N(μ,0.1²)。抽取10个样本：9.9,10.1,10.2,9.7,9.9,9.9,10.0,10.5,10.1,10.2。在 α=0.05 下检验是否可认为 μ=10。
标准结果：H0:μ=10，H1:μ≠10。样本均值 x̄=10.05。U=(10.05-10)/(0.1/√10)≈1.581。因为 |U|<1.96，所以不拒绝 H0，可认为均值为10。
考试步骤：
  1. 写原假设 H0 和备择假设 H1。
  2. 已知 σ，所以用 U 检验。
  3. 双侧检验 α=0.05，临界值 1.96。
  4. 计算统计量并比较。
  5. 写结论，不能只写“接受”，要结合题目语言。
我的提醒：考试如果考假设检验，这题模板价值极高。
L9高频模板置信区间 + 假设检验：σ²未知，用 t
题目
某总体 X~N(μ,σ²)，抽样 n=36，x̄=24.92，s=1.974。①求 μ 的 0.95 置信区间；②在 α=0.05 下检验是否可认为 μ=25。
标准结果：① σ未知，用 t 区间：x̄±t0.025(35)s/√n =24.92±2.0301×1.974/6=(24.2521,25.5879)。② H0:μ=25，H1:μ≠25。t=(24.92-25)/(1.974/6)≈-0.2432，|t|<2.0301，不拒绝 H0，可认为均值为25。
考试步骤：
  1. σ未知，用 t 分布，自由度 n-1=35。
  2. 置信区间和假设检验用的是同一个标准误 s/√n。
  3. 双侧检验看 |t| 是否超过临界值。
我的提醒：这一题把“区间估计”和“假设检验”合在一起，很像期末大题。

六、最容易丢分的地方

1. 把 P(AB)=0 当成 AB=空集
概率为0不一定代表事件不可能发生。选择题 C5 就在考这个坑。
2. σ 已知/未知搞错
σ 已知用 U/z；σ 未知用 t，自由度 n-1。
3. 置信区间临界值用错
95% 双侧：z0.025=1.96；t 要看自由度。
4. 二维表行列加错
求 X 边缘就固定 X，把对应所有 Y 加起来；求 Y 反过来。
5. CLT 方差漏开根号
二项近似正态：均值 np，标准差 √np(1-p)。
6. 假设检验结论太短
不要只写“接受 H0”。要写“在 α=0.05 下，可认为均值为……”
