专题一：市场失灵与财政职能

1纯公共物品最典型的特征组合是：

  1. 竞争性、排他性
  2. 非竞争性、非排他性
  3. 竞争性、非排他性
  4. 非竞争性、排他性
查看答案与解析

答案：B

国防、路灯等纯公共物品同时具有非竞争性和非排他性。

2某企业排污使周边居民健康受损，但污染成本未计入产品价格。这首先属于：

  1. 公共物品
  2. 正外部性
  3. 负外部性
  4. 收入分配不公
查看答案与解析

答案：C

企业的私人成本小于社会成本，市场产量会偏多。

3政府购买城市轨道交通服务，但由私人企业施工。下列说法正确的是：

  1. 私人生产等于私人供给
  2. 政府供给必须政府生产
  3. 供给主体与生产主体可以分离
  4. 该服务必然是纯公共物品
查看答案与解析

答案：C

政府可筹资和决定供给量，再通过采购或外包让私人生产。

4为什么搭便车会导致公共物品市场供给不足？

查看答案与解析

答案：个人有隐瞒偏好和不付费的激励。

非排他性使未付费者仍能受益，私人生产者难以收回成本，因此供给低于社会最优。

5比较治理污染的排污税与排污权交易。

查看答案与解析

答案：二者都使外部成本内部化。

排污税确定单位排放价格，排放量由企业选择；排污权交易确定总量，权利价格由市场形成。前者价格更确定，后者总量更确定。

专题二：财政支出、社会保障与财政收入

1失业保险金属于：

  1. 购买性支出
  2. 转移性支出
  3. 政府投资
  4. 国防支出
查看答案与解析

答案：B

政府没有取得等价商品或劳务，资金单方面转移给个人。

2战争结束后财政支出难以回到战前水平，最适合用什么理论解释？

  1. 瓦格纳法则
  2. 替代效应理论
  3. 李嘉图等价
  4. 拉弗曲线
查看答案与解析

答案：B

非常事件造成支出跳跃，危机后因重建和政府职能扩张而维持较高平台。

3说明养老保险三支柱。

查看答案与解析

答案：第一支柱基本养老保险；第二支柱企业年金和职业年金；第三支柱个人养老金等。

答题时补充定位：政府保基本、单位与个人补充、个人自愿积累。

4现金补贴和价格补贴对消费选择有何不同？

查看答案与解析

答案：现金补贴主要产生收入效应；价格补贴兼有收入效应和替代效应。

价格补贴改变相对价格，更可能扭曲消费结构；现金补贴给消费者更大选择空间。

5为什么地方政府容易依赖土地财政？

查看答案与解析

答案：事权与稳定财力不匹配、城镇化融资需求大、地方掌握土地资源配置权。

完整答案还要写短期建设作用和不可持续、房价、债务风险。

专题三：税收原理、税收制度与计算

1在其他条件相同下，某商品需求极缺乏弹性、供给较有弹性，商品税主要由谁承担？

  1. 消费者
  2. 生产者
  3. 政府
  4. 平均分担
查看答案与解析

答案：A

谁的弹性小，谁更难逃避税负。

2横向公平是指：

  1. 高收入者多缴税
  2. 能力相同者税负相同
  3. 受益多者一定多缴税
  4. 所有人缴相同税额
查看答案与解析

答案：B

纵向公平才强调能力不同者承担不同税负。

3拉弗曲线能否证明所有减税都会增加税收收入？

查看答案与解析

答案：不能。

只有原税率处于禁区、减税显著扩大税基时，减税才可能增收；低税率区减税通常减少收入。

4个人综合所得应纳税所得额197600元，应纳税额是多少？

查看答案与解析

答案：22600元。

197600×20%-16920=22600。

5房地产税可能如何影响租金？

查看答案与解析

答案：是否转嫁取决于住房供求弹性、空置率、租赁市场竞争和税制设计。

不能简单说房东一定完全转嫁；短期供给较固定时，房东可能承担较多，市场紧张时租客承担比例可能上升。

专题四：公债、预算、财政体制与金融联系

1政府借债最主要凭借的是：

  1. 政治权力
  2. 国家信用
  3. 财产没收权
  4. 货币发行权
查看答案与解析

答案：B

公债有偿、通常自愿，区别于税收。

2李嘉图等价成立时，政府减税并发债为什么不必然刺激消费？

查看答案与解析

答案：居民预见未来增税还债，会把减税所得储蓄起来。

现实中流动性约束、有限寿命和不完全预期使其难完全成立。

3预算批准权属于：

  1. 财政部门
  2. 各级政府
  3. 各级人民代表大会
  4. 审计机关
查看答案与解析

答案：C

财政部门负责具体编制和执行管理，人大行使审批监督权。

4为什么流动性强的税基更适合中央政府？

查看答案与解析

答案：避免地方税收竞争导致税基迁移，并有利于统一征管和宏观调控。

房地产等不流动税基通常更适合地方。

52026年以特别国债支持国有大型商业银行补充资本，体现哪些财政—金融联系？

查看答案与解析

答案：公债工具、财政注资、金融稳定与风险处置。

财政资金增强银行资本和信贷承载能力，但要评价债务成本、治理约束和资金使用效率。

专题五：财政政策乘数与财政—金融协同

1边际消费倾向b=0.8，政府购买增加100亿元，简单模型中收入增加多少？

查看答案与解析

答案：500亿元。

政府购买乘数1/(1-0.8)=5，故增加500亿元。

2同上，税收增加100亿元，收入变化多少？

查看答案与解析

答案：减少400亿元。

税收乘数=-b/(1-b)=-4。

3为什么现实财政乘数往往小于简单模型？

查看答案与解析

答案：存在储蓄、进口、税收、价格上涨、利率上升等漏出。

还受经济周期、货币政策配合、居民预期、支出效率和融资方式影响。

4扩张性财政政策会不会一定挤出私人投资？

查看答案与解析

答案：不一定。

充分就业附近、利率上升时挤出较明显；衰退和产能闲置时，需求改善可能反而带动私人投资。

5财政政策与货币政策如何协同？

查看答案与解析

答案：财政决定支出、税收与债务，货币政策影响利率和流动性；协调可增强需求管理和风险处置。

财政扩张若配合适度流动性，融资成本和挤出效应可能较低；但过度协同也可能增加通胀和债务风险。

第四版教材定位题 24题

这一组最重要：题目按老师第四版教材的章节语言与逻辑原创设计。先不看答案口述，每题目标是用60-120字回答，并能说出教材页码位置。

1第四版为什么把财政学称为研究“一只巨兽”的经济学？ p.1-6

查看答案与解析

答案：因为财政学研究政府这一规模巨大、权力特殊的经济主体，以及个人、市场与国家之间的资源分配关系。

答题重点不是文学比喻，而是政府凭借公共权力取得收入并配置资源，其行为同时涉及经济、政治与法律。

2实证分析与规范分析分别回答什么问题？ p.6-9

查看答案与解析

答案：实证分析回答“是什么、为什么”；规范分析回答“应该怎样、好不好”。

财政材料题常先做实证机制分析，再作公平、效率和政策选择的规范评价。

3第四版如何从三层理解广义市场失灵？ p.16-37

查看答案与解析

答案：效率缺失、公平缺失、经济失衡。

公共物品、外部性等属于效率问题；基尼系数和分配差距属于公平问题；失业、通胀和周期波动属于稳定问题。

4为什么市场失灵并不意味着政府干预越多越好？ p.35-53

查看答案与解析

答案：政府干预也可能出现信息不足、激励扭曲、寻租和低效率，即政府失灵。

正确结论是合理划分政府与市场边界，并比较干预的社会收益与成本。

5三大财政职能与三类市场失灵如何对应？ p.38-46

查看答案与解析

答案：资源配置对应效率缺失；分配职能对应公平缺失；稳定职能对应经济失衡。

这是第二、三章之间最重要的逻辑桥梁。

6购买性支出为什么比转移性支出更直接影响资源配置？ p.61-66

查看答案与解析

答案：购买性支出由政府直接购买商品和劳务，立即形成需求并占用生产要素。

转移性支出先改变受领者收入，再由其消费或投资选择间接影响资源配置。

7瓦格纳法则中的增长主要是绝对增长还是相对增长？ p.67-73

查看答案与解析

答案：重点是相对增长，即财政支出增长快于国民收入，支出占比提高。

只看到财政支出金额变大不能证明瓦格纳法则成立，还要与GDP或国民收入增长比较。

8成本—效益分析为什么要使用贴现？ p.74-81

查看答案与解析

答案：因为不同年份的成本和效益不能直接相加，需要折算为同一时点的现值。

净现值大于零通常说明项目社会效益现值超过社会成本现值。

9一般公共服务支出是否等同于行政管理费？ p.82-85

查看答案与解析

答案：不等同。一般公共服务支出口径更广，是政府提供基本公共管理和服务的成本。

判断题出现“完全等同”应判错。

10教育支出为何具有分配职能？ p.89-92

查看答案与解析

答案：公共教育降低家庭受教育成本，改善低收入群体的人力资本机会，从而影响代际流动和收入分配。

同时教育具有正外部性和信贷市场失灵，因此也体现配置职能。

11财政补贴最本质的经济作用是什么？ p.104-109

查看答案与解析

答案：改变相对价格和经济主体的预算约束，从而影响供求数量与结构。

补贴不是越多越好，长期补贴可能形成依赖并保护低效率生产。

12全口径财政收入为什么不能把四本预算收入简单相加？ p.110-126

查看答案与解析

答案：预算之间存在调入、结转和财政补助等重复计算，需要合并抵销。

这是教材对宏观财政收入统计口径的精细提醒。

13税收中性是否等于税收没有任何经济影响？ p.132-137

查看答案与解析

答案：不是。税收中性要求尽量减少税款之外的额外扭曲和超额负担。

任何税收通常都会产生收入效应，中性强调把替代扭曲降到较低程度。

14为什么税负转嫁必须通过价格变动实现？ p.137-146

查看答案与解析

答案：税负转嫁是纳税人利用交易价格变化，把经济负担转给交易对方。

若没有价格或报酬调整，只是纳税人自己承担，就不构成转嫁。

15课税范围越广，税负通常更容易还是更难转嫁？ p.137-146

查看答案与解析

答案：通常更容易转嫁。

范围越广，购买者越难找到未税替代品，需求替代效应较弱。

16全额累进与超额累进的关键区别是什么？ p.147-153

查看答案与解析

答案：全额累进对全部税基适用最高档税率；超额累进只对超过级距的部分适用更高税率。

个人综合所得采用超额累进，可避免临界点税负跳跃。

17增值税的抵扣链条为什么具有自我控制作用？ p.153-166

查看答案与解析

答案：购买方取得进项抵扣需要销售方开票申报，交易双方形成相互制约。

但发票管理复杂，也会产生虚假抵扣等征管风险。

18财产税为什么通常适合作为地方税？ p.171-180、p.236-248

查看答案与解析

答案：财产尤其房地产税基不易流动，地方掌握信息较多，且税收与地方公共服务受益联系较强。

这同时连接第八章财产税和第十一章收入划分。

19公债的国家信用属性与税收的政治权力属性有何不同？ p.187-200

查看答案与解析

答案：公债以还本付息承诺吸引自愿认购，具有有偿性；税收依法律强制征收且无直接偿还。

两者都可筹资，但权利义务关系不同。

20为什么预算既是经济文件也是政治和法律文件？ p.201-228

查看答案与解析

答案：预算配置稀缺公共资源，反映政策选择；又须经立法机关审批并依法执行。

教材强调预算是政治争取资源的记录，也是控制政府行为的法律制度。

21预算绩效管理的核心问题是什么？ p.219起

查看答案与解析

答案：财政资金是否实现预定产出和社会效果，即花钱是否有效。

材料题可从目标、成本、产出、效果和责任追踪五方面评价。

22为什么收入分配和稳定职能主要由中央政府承担？ p.231-234

查看答案与解析

答案：地方间人员和资本流动会削弱地方再分配；宏观稳定需要全国统一政策和较强融资能力。

地方仍可在中央制度框架内承担具体执行和地方性稳定责任。

23分税制为何必须配套转移支付？ p.236-248

查看答案与解析

答案：地方税源与支出责任不可能完全匹配，且地区财力差异较大。

转移支付用于弥补纵向缺口和促进地区间基本公共服务均等化。

24财政政策时滞会怎样影响政策效果？ p.257-260

查看答案与解析

答案：政策从发现问题到产生效果存在认识、行政、决策、执行和效果五种时滞，可能导致政策错过最佳时机。

认识和行政时滞属于研究判断过程；决策、执行和效果时滞直接影响政策落地。材料题不能只写乘数，还要评价时滞与退出时点。

1某居民全年工资薪金收入300000元，全年三险一金36000元；一个正在接受学历教育的子女，由本人扣除100%；本人为独生子女且父母年满60岁。计算全年综合所得个税。

查看答案与解析

答案：全年应纳税所得额144000元；应纳税额11880元。

扣除合计=60000+36000+子女教育24000+赡养老人36000=156000元；税基=300000-156000=144000元；税额=144000×10%-2520=11880元。
