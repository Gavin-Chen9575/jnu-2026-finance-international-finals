三、名词解释得分点

  1. 汇率：两种货币之间的兑换比率，是一种货币用另一种货币表示的价格。按标价方法可分为直接标价法和间接标价法，汇率变动会影响贸易、资本流动和国际收支。
  2. 远期汇率：外汇买卖双方在当前约定、未来某一日期交割外汇时使用的汇率。它可用于锁定汇率风险，并与两国利率差异和利率平价有关。
  3. 欧洲债券市场：在债券面值货币发行国以外发行和流通国际债券的市场。“欧洲”是历史名称，不表示市场必须在欧洲。判断关键是发行地与计价货币发行国不同。
  4. 国际收支平衡表：系统记录一国居民与非居民在一定时期内全部经济交易的统计报表。主要包括经常账户、资本账户、金融账户、储备资产和净误差与遗漏，采用复式记账。
  5. 马歇尔-勒纳条件：本币贬值改善贸易收支的长期条件，即出口需求价格弹性和进口需求价格弹性绝对值之和大于 1。若不满足，贬值不一定改善贸易收支。

四、计算题

  1. F = 7.20 x 1.02 / 1.05 = 6.994。F < S，美元远期贴水，人民币远期升水。
  2. 货物余额 = 500 - 420 = 80；服务余额 = 100 - 160 = -60；收入余额 = 40 - 70 = -30；经常转移 = 30 - 10 = 20。经常账户余额 = 80 - 60 - 30 + 20 = 10，顺差 10。

五、简答题得分点

  1. 欧洲货币/欧洲债券：二者属于离岸金融市场；“欧洲”不是地理概念，而是历史名称；欧洲货币市场是在货币发行国境外经营该货币存贷款业务的市场，如美国境外的美元存贷款市场；欧洲债券市场是在债券面值货币发行国以外发行和流通债券的市场；考试必须写“离岸”和“发行国境外/计价货币发行国以外”，不能写成位于欧洲的市场。
  2. 国际收支表：国际收支平衡表记录居民与非居民在一定时期内的全部经济交易；经常账户包括货物、服务、初次收入和二次收入；资本账户包括资本转移和非生产非金融资产交易；金融账户包括直接投资、证券投资、其他投资、储备资产等；贷方通常表示外汇流入、收入增加、负债增加或资产减少；借方通常表示外汇流出、支出增加、资产增加或负债减少；出口记贷方，进口记借方，外国来华投资记金融账户贷方，本国购买外国资产记金融账户借方。
  3. PPP 与实际汇率：购买力平价是关于名义汇率和两国价格水平关系的理论，绝对 PPP 为 S=P/P*，相对 PPP 讨论汇率变动和通胀差；实际汇率是名义汇率经两国价格水平调整后的相对价格，常写作 Q=S x P*/P；PPP 解释长期汇率，实际汇率更常用于衡量国际竞争力。

三、名词解释得分点

  1. 离岸金融市场：非居民之间以境外货币为交易对象，在货币发行国境外进行资金融通的国际金融市场。其监管通常相对宽松，但不是完全无监管。
  2. 抛补利率平价：在无套利条件下，本币投资收益应等于换成外币投资并通过远期合约锁定汇率后的收益。公式为 F = S x (1+i_d)/(1+i_f)。
  3. 实际汇率：名义汇率经过两国价格水平调整后的相对价格，常写为 Q = S x P*/P。它反映一国商品的国际竞争力，Q 上升通常表示本国实际贬值、竞争力增强。
  4. 经常账户：国际收支平衡表中记录货物、服务、初次收入和二次收入的账户，反映真实资源交易和收入转移状况。
  5. 金融危机：金融体系中全部或大部分金融指标出现急剧、短暂、超周期恶化，并导致金融功能受损的状态。可表现为货币危机、银行危机、债务危机、资产市场危机等。

四、计算题

  1. 绝对 PPP 汇率 S = P/P* = 700/100 = 7.00 元/美元。市场汇率 7.30 高于 PPP 汇率，在直接标价法下美元相对更贵，人民币相对 PPP 低估。
  2. 弹性和 = 0.6 + 0.7 = 1.3 > 1，满足马歇尔-勒纳条件。因此本币贬值长期有助于改善贸易收支；但短期可能因合同固定、数量调整滞后等出现 J 曲线效应，即先恶化后改善。

五、简答题得分点

  1. 不可能三角：固定汇率、资本自由流动、货币政策独立性不能同时完全实现；香港联系汇率制度选择汇率稳定和资本自由流动，因此货币政策自主性较弱，利率受美元体系影响；中国作为大型经济体重视货币政策自主性，因此采取有管理浮动汇率和渐进资本项目开放；结论是一国制度选择要在稳定汇率、开放资本和政策自主之间权衡。
  2. 政策效果比较：浮动汇率下，货币扩张使利率下降、资本流出、本币贬值、净出口增加，货币政策较有效；浮动汇率下财政扩张使利率上升、资本流入、本币升值、净出口下降，财政效果被部分抵消；固定汇率下货币扩张引发贬值压力，央行卖外汇买本币，货币扩张被抵消，货币政策受限；固定汇率下财政扩张引发升值压力，央行买外汇投放本币，财政政策效果被放大。
  3. 三大体系：金本位以黄金为锚，各国货币与黄金挂钩，汇率相对固定但货币政策受黄金约束；布雷顿森林体系以美元-黄金为核心，美元与黄金挂钩、其他货币与美元挂钩，本质是固定汇率体系；牙买加体系承认浮动汇率合法化，黄金非货币化，储备资产多元化，灵活性提高但汇率波动和国际协调问题加大。
