模拟卷 A 答案

一、判断题

1. 错　2. 对　3. 错　4. 对　5. 对　6. 错　7. 对　8. 对　9. 错　10. 对

二、单项选择题

1. B　2. C　3. B　4. B　5. A　6. B　7. A　8. A　9. B　10. C

三、名词解释得分点

  1. 远期汇率：外汇买卖双方在当前签订远期合约，约定未来某一日期交割外汇时使用的汇率。它用于锁定汇率风险，也与两国利率差异和利率平价有关。
  2. 欧洲货币市场：在货币发行国境外经营该种货币存贷款业务的离岸金融市场。“欧洲”是历史名称，不表示市场必须在欧洲。例如美国境外的美元存贷款市场属于欧洲美元市场。
  3. 国际收支平衡表：系统记录一国居民与非居民在一定时期内全部经济交易的统计报表，主要包括经常账户、资本账户、金融账户、储备资产和净误差与遗漏，采用复式记账原则。
  4. J 曲线效应：本币贬值后，贸易收支短期可能因合同固定、数量调整滞后等原因先恶化，随后出口增加、进口减少，长期逐渐改善，变化路径类似字母 J。
  5. 不可能三角：固定汇率、资本自由流动和货币政策独立性三者不能同时完全实现。一国最多同时选择其中两个，必须在开放经济政策目标之间取舍。

四、计算/记账题

  1. F = 7.20 x 1.02 / 1.05 = 6.994。F < S，美元远期贴水，人民币远期升水。
  2. 货物余额 = 500 - 420 = 80；服务余额 = 100 - 160 = -60；收入余额 = 40 - 70 = -30；经常转移 = 30 - 10 = 20。经常账户余额 = 80 - 60 - 30 + 20 = 10，顺差 10。
  3. 出口商品：经常账户货物贷方 +300。货款存入 B 国银行使 A 国对外资产增加：金融账户借方 -300。复式记账一贷一借。

五、简答题得分点

  1. 欧洲债券市场：它属于离岸金融市场；“欧洲”不是地理概念；判断关键是发行地点是否在债券面值货币发行国之外；例如在美国以外发行的美元债券可称欧洲美元债券；不要写成“欧洲发行的债券市场”。
  2. M-L 与 J 曲线：M-L 条件说明本币贬值长期改善贸易收支的弹性条件；出口和进口需求价格弹性之和大于 1；J 曲线说明贬值后的动态调整过程；短期因合同、价格粘性和数量滞后可能先恶化，长期才改善；二者一个讲长期条件，一个讲时间路径。
  3. 固定汇率下货币扩张：货币扩张使利率下降；资本流出；本币出现贬值压力；央行为维持固定汇率卖出外汇、买入本币；外汇储备减少，货币供给被回收；最初扩张被抵消，因此长期效果受限，资本流动越强越明显。

六、论述题得分点

可按“定义 - 三个目标 - 机制 - 例子 - 评价”写。不可能三角指固定汇率、资本自由流动、货币政策独立不能同时完全实现。香港联系汇率制度选择汇率稳定和较高资本自由流动，因此利率和货币政策较多受美元体系影响，货币政策自主性受限。中国作为大型经济体重视货币政策自主性，因此选择有管理浮动汇率和渐进资本项目开放，在汇率稳定、资本流动和政策独立之间权衡。结论写开放经济政策没有免费午餐，制度选择取决于发展阶段、金融稳定和宏观调控目标。

模拟卷 B 答案

一、判断题

1. 对　2. 对　3. 错　4. 对　5. 对　6. 错　7. 错　8. 对　9. 对　10. 错

二、单项选择题

1. B　2. C　3. C　4. A　5. B　6. B　7. B　8. B　9. C　10. C

三、名词解释得分点

  1. 直接标价法：以一定单位外国货币为标准，折算为若干单位本国货币的标价方法。直接标价法下，汇率上升表示外币升值、本币贬值。
  2. 抛补利率平价：在无套利条件下，本币投资收益应等于换成外币投资并通过远期合约锁定汇率后的收益。公式为 F = S x (1+i_d)/(1+i_f)。
  3. 实际汇率：名义汇率经过两国价格水平调整后的相对价格，常写为 Q = S x P*/P。它反映一国商品的国际竞争力，Q 上升通常表示本国实际贬值。
  4. 经常账户：国际收支平衡表中记录货物、服务、初次收入和二次收入的账户，反映真实资源交易和收入转移状况。
  5. 金融危机：金融体系中全部或大部分金融指标出现急剧、短暂、超周期恶化，并导致金融功能受损的状态。可表现为货币危机、银行危机、债务危机、资产市场危机等。

四、计算/记账题

  1. 绝对 PPP 汇率 S = P/P* = 700/100 = 7.00 元/美元。市场汇率 7.30 高于 PPP 汇率，在直接标价法下美元相对更贵，人民币相对 PPP 低估。
  2. 弹性和 = 0.6 + 0.7 = 1.3 > 1，满足马歇尔-勒纳条件。因此本币贬值长期有助于改善贸易收支。但短期可能因 J 曲线效应先恶化。
  3. 捐赠商品属于经常账户二次收入/经常转移借方 -900；同时商品出口形成货物贷方 +900。若按无偿商品转移处理，关键要写出对外无偿转移为借方。

五、简答题得分点

  1. 国际收支账户：经常账户记录货物、服务、初次收入和二次收入；资本账户记录资本转移和非生产非金融资产交易；金融账户记录直接投资、证券投资、金融衍生品、其他投资和储备资产等金融资产负债变化；净误差与遗漏用于统计调整；采用复式记账。
  2. 浮动汇率下政策效果：货币扩张使利率下降、资本流出、本币贬值、净出口增加，因此货币政策通常较有效；财政扩张使收入和利率上升、资本流入、本币升值、净出口下降，财政政策效果被部分抵消；资本流动越强，这种汇率反馈越明显。
  3. 三大体系区别：金本位以黄金为锚，各国货币与黄金挂钩，货币供给受黄金约束；布雷顿森林体系以美元-黄金为核心，美元与黄金挂钩、其他货币与美元挂钩，本质是固定汇率体系；牙买加体系承认浮动汇率合法化，黄金非货币化，储备资产多元化，灵活性增强但汇率波动和协调问题更突出。

六、论述题得分点

可按“人民币汇率制度改革主线 - 短期因素 - 长期因素 - 政策评价”写。改革主线是从较强行政管理和相对固定安排，逐步走向以市场供求为基础、参考一篮子货币、有管理浮动和更高弹性。短期汇率波动受资本流动、市场预期、利差、央行干预、国际金融市场情绪和美元走势影响。长期走势受通胀差、劳动生产率、经济增长、国际收支、贸易竞争力、制度安排和货币政策可信度影响。人民币汇率制度体现不可能三角下的政策取舍：中国重视货币政策自主性，因此资本项目开放和汇率弹性采取渐进安排。有管理浮动有利于兼顾市场化、稳定性和金融安全。
