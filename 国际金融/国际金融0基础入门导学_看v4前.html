1. 这门课到底学什么

国际金融研究的是：一个国家打开国门以后，货币、汇率、资本流动、国际收支和宏观政策之间会怎样互相影响。

如果只用一句话概括：国际金融就是在开放经济条件下，研究“钱怎样跨国流动、汇率怎样形成、国家怎样在稳定汇率和保持政策自主之间做选择”。

微观层面 外汇市场里，银行、企业、投资者如何买卖货币，如何用远期汇率避险或套利。
宏观层面 一国出口、进口、资本流入流出如何体现在国际收支表里。
制度层面 国家选择固定汇率还是浮动汇率，为什么不可能同时拥有所有好处。

你看 v4 时会遇到很多名词：CIP、PPP、RER、BoP、BP 曲线、蒙代尔-弗莱明、不可能三角、布雷顿森林体系、金融危机模型。它们不是零散知识点，而是在回答同一个问题：跨国资金和商品交易会怎样改变汇率、国际收支和政策效果。

3. 一张图理解全课

把这门课想成五层楼，从最底层的“货币兑换”一路走到最高层的“国际金融危机”。

1 外汇两国货币怎么换，汇率怎么报价。
2 平价汇率、利率、物价之间应当有什么关系。
3 国际收支跨国交易如何记账，顺差逆差从哪里来。
4 宏观政策财政、货币政策在开放经济中为什么效果变了。
5 制度与危机固定还是浮动，资本是否开放，危机会怎样爆发。

你之后看到任何概念，都可以问它属于哪一层：

  • 远期汇率、买入价、卖出价：属于外汇市场。
  • CIP、UIP、PPP、实际汇率：属于平价条件。
  • 经常账户、金融账户、借方贷方：属于国际收支。
  • IS-LM-BP、蒙代尔-弗莱明：属于开放经济宏观政策。
  • 不可能三角、金本位、布雷顿森林、牙买加体系、金融危机模型：属于制度与危机。

4. 先学会这套语言

国际金融最容易让 0 基础同学卡住的地方，不是难，而是它有自己的表达方式。先把下面几个词变成熟人。

词入门解释考试写法方向
外汇不是“外国现金”这么窄，而是以外币表示、可用于国际支付的资产。外币现金、存款、票据、有价证券都可纳入广义外汇。
汇率一种货币用另一种货币表示的价格。先判断直接标价法还是间接标价法，再判断升贬值。
资本流动钱跨国投资、借贷、买债券股票、设厂。流入流出会影响汇率、利率和金融账户。
居民/非居民国际收支里看经济利益中心，不简单看国籍。本国居民和非居民之间的交易才进入国际收支。
开放经济国家不只和自己交易，还和世界发生贸易和资本往来。开放后，财政货币政策效果会受汇率和资本流动影响。
学习诀窍：遇到一个概念，先问三个问题：它管的是商品交易、金融交易还是政策选择？它影响的是汇率、国际收支还是利率？它适合出名词解释、计算题还是简答题？

5. 汇率与外汇市场

汇率是本课程的入口。外汇市场里交易的是不同货币，汇率就是交易价格。

5.1 直接标价法是第一道门

中国常见的 USD/CNY=7.20，意思是 1 美元等于 7.20 元人民币。这是直接标价法：用本币表示外币价格。

直接标价法：S 上升 = 外币更贵 = 本币贬值
直接标价法：S 下降 = 外币更便宜 = 本币升值

这件事一定要熟，因为 PPP、RER、远期升贴水、人民币高估低估，都会回到这个判断。

5.2 外汇市场不是菜市场式固定摊位

PPT 和录音都强调现代外汇市场很多交易是场外市场 OTC，由银行、金融机构、企业、央行等主体参与。报价也有买入价、卖出价、中间价。

价格含义别混
买入价银行买入外汇的价格。站在银行角度，不是站在客户角度。
卖出价银行卖出外汇的价格。通常卖出价高于买入价。
即期汇率成交后短期交割使用的汇率。不是所有汇率都是即期汇率。
远期汇率现在约定、未来交割时使用的汇率。不是对未来即期汇率的保证。

5.3 人民币汇率制度是一道开放题素材

老师特别提到人民币汇率。你不用一开始背完整时间线，但要知道主线：人民币汇率制度改革总体方向是市场化、弹性化、有管理浮动，且和中国在“不可能三角”中的取舍有关。

一句能套很多题的话：中国作为大型经济体重视货币政策自主性，因此人民币汇率制度不是完全固定，也不是完全自由浮动，而是在市场供求基础上实行有管理浮动，并配合渐进式资本项目开放。

6. 平价条件和远期汇率

平价条件就是“如果市场没有白捡的钱，汇率、利率、物价之间应该大致满足什么关系”。课堂 PPT 第2章讲 CIP、UIP、市场效率，第4章讲 PPP 和实际汇率。

6.1 CIP：远期汇率和利率的关系

抛补利率平价 CIP 是无套利条件。意思是：你把钱存在本国，或者换成外币去外国投资并用远期合约锁定未来换回来的汇率，两个收益应该一样。否则就有人套利，直到差异消失。

F = S x (1 + i_d) / (1 + i_f)
默认 S 为直接标价法：本币/外币
i_d = 本国利率，i_f = 外国利率

直觉：本国利率更高时，为了让本币投资和外币投资收益相等，外币远期通常会升水；反过来，本国利率更低时，外币远期通常贴水。

6.2 PPP：汇率和物价的关系

购买力平价 PPP 的直觉是：同一篮子商品在两国用同一种货币表示后，价格不该长期差太多。

绝对 PPP：S = P / P*
相对 PPP：汇率变动率 ≈ 本国通胀率 - 外国通胀率

如果本国通胀长期高于外国，本国货币的购买力下降，本币长期倾向贬值。直接标价法下，这通常表现为 S 上升。

6.3 实际汇率 RER：看竞争力

Q = S x P* / P

在直接标价法下，Q 上升通常可理解为本国商品相对便宜，本国实际贬值，国际竞争力增强；Q 下降则相反。

先别怕公式：CIP 管“利率差怎样变成远期升贴水”；PPP 管“物价差怎样影响长期汇率”；RER 管“名义汇率扣除物价后，竞争力有没有变”。

7. 国际收支

国际收支 BoP 是第10章的核心。它记录一国居民与非居民在一定时期内发生的全部经济交易。

7.1 三大账户

账户记录什么直觉
经常账户货物、服务、初次收入、二次收入。真实商品服务和收入转移。
资本账户资本转移、非生产非金融资产交易。考试里一般不是最核心。
金融账户直接投资、证券投资、其他投资、储备资产等。钱怎样跨国买资产、投资、借贷。

7.2 借贷方向用“外汇流入流出”先判断

交易账户方向原因
本国出口商品收到美元经常账户-货物贷方 +外汇流入。
本国进口机器支付美元经常账户-货物借方 -外汇流出。
外国游客来本国消费经常账户-服务贷方 +服务出口，收到外汇。
本国学生去美国留学付学费经常账户-服务借方 -服务进口，支付外汇。
外国企业来本国投资建厂金融账户-直接投资贷方 +资本流入，本国对外负债增加。
本国居民购买美国股票金融账户-证券投资借方 -资本流出，本国对外资产增加。

7.3 国际收支失衡理论是在解释“为什么不平衡”

  • 弹性论：本币贬值能否改善贸易收支，要看进出口需求价格弹性。
  • 马歇尔-勒纳条件：出口需求弹性和进口需求弹性之和大于 1，本币贬值长期才有助于改善贸易收支。
  • J 曲线：贬值后贸易收支可能短期先恶化，长期再改善。
  • 吸收论：B = Y - A，改善国际收支不能只看汇率，还要看收入和国内总支出。
  • 货币论：国际收支失衡本质上与货币供求失衡有关。

8. 开放经济政策

第11章的 IS-LM-BP 和蒙代尔-弗莱明模型，解决的是一个核心问题：开放经济中，财政政策和货币政策为什么会因为汇率制度和资本流动程度不同而效果不同。

IS 曲线 商品市场均衡。收入、利率和总需求之间的关系。
LM 曲线 货币市场均衡。货币供给、货币需求、收入和利率之间的关系。
BP 曲线 国际收支均衡。经常账户和资本流动共同决定外部平衡。

8.1 浮动汇率下

浮动汇率下，央行不承诺维持某个固定汇率，汇率会帮助经济调整。

  • 货币扩张：利率下降，资本流出，本币贬值，出口竞争力增强，收入上升。通常比较有效。
  • 财政扩张：收入和利率上升，资本流入，本币升值，净出口下降，财政刺激被部分抵消。

8.2 固定汇率下

固定汇率下，央行要维护汇率，所以货币供给常常被外汇市场干预反向改变。

  • 货币扩张：利率下降，资本流出，本币贬值压力出现。央行为维持汇率卖外汇、买本币，货币扩张被抵消。通常效果受限。
  • 财政扩张：收入和利率上升，资本流入，本币升值压力出现。央行为维持汇率买外汇、投放本币，财政扩张被进一步放大。通常较有效。
模型不用一开始画得很熟。先记政策传导链：政策改变收入和利率，利率引起资本流动，资本流动影响汇率，汇率再影响净出口和央行干预。

9. 汇率制度与国际货币体系

第12章把视角从“一个市场”拉到“一个国家怎样选择制度”。核心是：固定汇率、资本自由流动、货币政策独立，这三个目标不能同时完全实现。

9.1 不可能三角

目标含义代价
固定汇率汇率保持稳定，降低贸易和投资不确定性。央行要用储备和货币政策维护汇率。
资本自由流动资金可以自由跨国流入流出。外部利率和市场情绪会影响本国金融环境。
货币政策独立央行能按本国经济状况加息、降息、调节流动性。如果还要固定汇率和资本自由流动，独立性会被削弱。

香港联系汇率制度可理解为更重视汇率稳定和资本自由流动，因此货币政策自主性较弱。中国更重视货币政策自主性，所以采取有管理浮动和渐进资本开放。

9.2 三大国际货币体系

体系核心锚特点主要问题
金本位黄金各国货币与黄金挂钩，汇率相对固定。货币供给受黄金约束，国内政策空间小。
布雷顿森林体系美元-黄金美元与黄金挂钩，其他货币与美元挂钩。美元作为储备货币和黄金兑换承诺之间存在矛盾。
牙买加体系多元储备资产承认浮动汇率合法化，黄金非货币化。汇率波动更大，国际协调更难。

10. 金融危机

第14章在老师录音里属于考试范围，但更偏“认知性”和“介绍性”。先把定义、表现和模型关键词抓住。

10.1 金融危机是什么

金融危机通常指金融体系中全部或大部分金融指标出现急剧、短暂、超周期恶化，并导致金融功能受损的状态。它不只是股市大跌，也包括货币危机、银行危机、债务危机、资本突然停止等。

10.2 四代危机模型先记关键词

模型核心解释关键词
第一代基本面不可持续导致固定汇率崩溃。财政赤字、货币扩张、储备耗尽。
第二代市场预期可能自我实现，政府在维持汇率和国内目标之间权衡。自我实现、多重均衡、政策权衡。
第三代金融部门脆弱、资产负债表错配、短期外债放大危机。银行、货币错配、资本逆转。
第四代全球金融网络、流动性和系统性风险导致危机传染。金融传染、全球周期、系统性风险。

亚洲金融危机常和固定汇率、资本流动、短期外债、金融部门脆弱联系起来；2008 年全球金融危机常和杠杆、金融创新、资产价格泡沫、系统性风险联系起来。

12. 入门自测

下面这些题不用写得很漂亮，只要能用自己的话说出来，就可以进入 v4。

1. 国际金融这门课研究什么？

研究开放经济下外汇、汇率、国际收支、资本流动、宏观政策、汇率制度和金融危机之间的关系。

2. 直接标价法下，USD/CNY 从 7.10 到 7.30，人民币怎么了？

人民币贬值。因为直接标价法下，汇率上升表示外币更贵、本币更便宜。

3. 欧洲货币市场为什么不是欧洲的货币市场？

因为“欧洲”是历史名称，本质是货币发行国境外经营该货币存贷款业务的离岸市场。例如美国境外的美元存贷款市场。

4. CIP、PPP、RER分别管什么？

CIP 管利率差和远期汇率；PPP 管物价差和长期汇率；RER 管名义汇率扣除物价后的国际竞争力。

5. 国际收支中，出口和进口通常记在哪边？

出口带来外汇流入，通常记贷方；进口需要对外支付，通常记借方。

6. 不可能三角是哪三个目标？

固定汇率、资本自由流动、货币政策独立性。三者不能同时完全实现。

7. 固定汇率下为什么货币政策受限？

货币扩张会带来利率下降、资本流出和本币贬值压力。央行为维持固定汇率需要卖外汇、买本币，回收货币供给，从而抵消最初的货币扩张。

8. 金融危机不只是股市危机，还可能表现为什么？

货币危机、银行危机、债务危机、资产市场危机、资本突然停止等。
