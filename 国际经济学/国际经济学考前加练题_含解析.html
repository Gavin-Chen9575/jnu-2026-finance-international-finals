国际经济学考前加练题：含答案与解析

定位：不再让你翻课后题和单独图形题。这份按老师录音和同学提醒加权，重点压在第8章最优关税、第9章进出口政策图形、第14-16章简单计算。

建议用法：先做题，不会就猜；每题做完立刻点开解析。图形题不用背图形长相，重点背“价格、产量、消费、贸易量、剩余、福利”的分析顺序。

一、选择题 45题 二、图形分析题 8题 三、计算题 12题 四、论述题 6题 最后背诵清单

一、选择题 45题

1. 判断一国是否具有比较优势，关键看什么？第3章

  1. 绝对劳动投入多少
  2. 机会成本高低
  3. 工资水平高低
  4. 出口数量多少
答案与解析

答案：B。比较优势看机会成本，不是看绝对生产效率。即使一国两种产品都更有效率，也仍可能在机会成本较低的产品上有比较优势。

2. 亚当·斯密的绝对优势理论认为，国际分工基础是？第3章

  1. 各国劳动生产率的绝对差异
  2. 各国需求偏好的相似性
  3. 各国货币供给差异
  4. 各国产品生命周期差异
答案与解析

答案：A。斯密强调绝对优势，李嘉图推进到比较优势。考试常考二者区别。

3. 封闭经济一般均衡中，生产点和消费点的关系通常是？第2章

  1. 可以不同
  2. 必须相同
  3. 消费点一定在生产可能性曲线外
  4. 生产点一定由世界价格决定
答案与解析

答案：B。封闭经济不能通过贸易交换，消费只能来自本国生产，所以生产点等于消费点。开放经济中两者可以分离。

4. 用社会无差异曲线衡量贸易利益时，曲线越高表示？第2章

  1. 社会福利越高
  2. 进口越少
  3. 出口越少
  4. 生产成本越高
答案与解析

答案：A。开放贸易后如果消费点移到更高的社会无差异曲线，说明社会福利提高。

5. 要素禀赋是指？第4章

  1. 一个产品使用某种要素的比例
  2. 一个国家拥有各种生产要素的相对丰裕程度
  3. 企业内部规模经济
  4. 消费者偏好结构
答案与解析

答案：B。要素禀赋是国家层面的概念；要素密集度是产品或产业层面的概念。

6. 赫克歇尔-俄林定理的基本结论是？第4章

  1. 各国出口密集使用其丰裕要素的产品
  2. 各国出口国内需求较大的产品
  3. 贸易必然使所有要素收入上升
  4. 贸易只由规模经济决定
答案与解析

答案：A。资本丰裕国出口资本密集型产品，劳动丰裕国出口劳动密集型产品。

7. 斯托尔珀-萨缪尔森定理主要说明贸易会影响什么？第4章

  1. 要素收入分配
  2. 只影响总产量，不影响收入分配
  3. 只影响汇率
  4. 只影响外汇储备
答案与解析

答案：A。商品相对价格变动会提高密集使用于该商品的要素真实报酬，降低另一要素真实报酬。

8. 罗伯津斯基定理讨论的是？第4章

  1. 某种要素增加对产出结构的影响
  2. 关税对消费者剩余的影响
  3. 汇率对国际收支的影响
  4. 倾销的法律判定
答案与解析

答案：A。在商品价格不变时，某要素增加会使密集使用该要素的产品产量扩大，另一产品产量收缩。

9. 里昂惕夫之谜挑战的是哪一理论的经验预测？第4章

  1. 绝对优势理论
  2. H-O理论
  3. 购买力平价理论
  4. 关税同盟理论
答案与解析

答案：B。按H-O，美国资本丰裕应出口资本密集品，但实证结果一度显示美国出口品劳动密集度更高，因此形成谜题。

10. 特定要素模型与长期H-O模型的关键区别是？第4章

  1. 短期有些要素不能跨部门流动
  2. 短期不存在劳动
  3. 长期不存在资本
  4. 短期没有商品价格
答案与解析

答案：A。老师强调短期核心原因就是要素无法自由跨行业流动，因此收入分配结论和长期不同。

11. 重叠需求理论更适合解释哪类贸易？第5章

  1. 收入水平相近国家之间的制成品贸易
  2. 完全由气候差异决定的农产品贸易
  3. 黄金本位制度
  4. 国际收支复式记账
答案与解析

答案：A。林德的重叠需求理论强调需求结构相似，常用于解释收入水平相近国家之间的产业内贸易。

12. 内部规模经济是指？第6章

  1. 单个企业产量扩大导致平均成本下降
  2. 整个行业扩大导致所有企业成本下降
  3. 政府征税导致财政收入增加
  4. 汇率升值导致进口便宜
答案与解析

答案：A。内部规模经济发生在企业内部；外部规模经济发生在行业或区域层面。

13. 规模经济和产品差异化更容易解释？第6章

  1. 产业内贸易
  2. 完全没有贸易
  3. 国际收支恒等式
  4. 固定汇率制度
答案与解析

答案：A。同类产品之间相互进出口，如汽车换汽车，通常用规模经济、不完全竞争和产品差异化解释。

14. 小国最优关税为零，原因是？第8章

  1. 小国不能影响世界价格，征税只有扭曲损失
  2. 小国没有消费者
  3. 小国出口一定为零
  4. 小国政府不能取得收入
答案与解析

答案：A。这是同学也提醒过的高频点。大国关税可能改善贸易条件，小国没有这个收益，所以最优关税为0。

15. 大国征收进口关税可能提高本国福利，是因为它可能？第8章

  1. 降低进口品世界价格，改善贸易条件
  2. 消除所有无谓损失
  3. 让消费者剩余上升
  4. 使全球福利提高
答案与解析

答案：A。大国关税的收益来自贸易条件改善，但仍有生产和消费扭曲。最优关税是本国净福利最大，不代表全球有效率。

16. 幼稚产业保护理论主张保护的是？第8章

  1. 未来可能具有竞争力、但当前尚未成熟的产业
  2. 所有亏损产业
  3. 所有进口替代产业
  4. 已经永久失去竞争力的产业
答案与解析

答案：A。幼稚产业不是“弱就保护”，要看未来能否成长、保护收益能否超过成本，以及政策是否能退出。

17. 战略性贸易政策通常建立在哪种市场结构上？第8章

  1. 完全竞争且无规模经济
  2. 不完全竞争和规模经济
  3. 没有政府行为
  4. 物物交换经济
答案与解析

答案：B。政府通过补贴等手段帮助本国企业争夺超额利润，前提往往是不完全竞争、寡头市场和规模经济。

18. 小国进口关税的直接影响不包括？第9章

  1. 国内价格上升
  2. 国内生产增加
  3. 国内消费增加
  4. 进口数量减少
答案与解析

答案：C。关税提高进口品国内价格，消费者减少消费，生产者扩大生产，进口减少。

19. 小国进口关税下，本国净福利变化通常是？第9章

  1. 增加
  2. 不变
  3. 减少，产生生产扭曲和消费扭曲
  4. 必然大幅增加
答案与解析

答案：C。小国无贸易条件收益，政府收入和生产者剩余增加不足以弥补消费者剩余损失，净损失为两个三角形。

20. 进口配额区别于关税的关键是？第9章

  1. 配额直接限制数量，配额租金归属不确定
  2. 配额不会提高国内价格
  3. 配额一定增加消费者剩余
  4. 配额没有任何福利损失
答案与解析

答案：A。如果政府拍卖许可证，租金像关税收入；如果被进口商拿走或寻租浪费，结果就不同。

21. 出口补贴对小国的本国福利影响通常是？第9章

  1. 净福利下降
  2. 消费者剩余上升
  3. 政府收入增加
  4. 国内价格下降
答案与解析

答案：A。出口补贴使国内价格上升，消费者受损，政府还要支出补贴，生产者受益但不足以覆盖损失。

22. 倾销通常是指？第9章

  1. 以低于国内价格或低于正常价值的价格出口
  2. 进口数量完全自由
  3. 国内价格高于出口价格就一定合法
  4. 政府补贴进口消费者
答案与解析

答案：A。反倾销一般需要证明存在倾销、造成损害、倾销与损害之间有因果关系。

23. 反倾销税的额度通常不应超过？第9章

  1. 倾销幅度
  2. 企业利润总额
  3. 消费者收入
  4. 外汇储备总额
答案与解析

答案：A。这是很适合选择题的细节：反倾销税不是随便征，通常不能超过倾销幅度。

24. 自由贸易区与关税同盟的主要区别是？第10章

  1. 关税同盟对外实行共同关税，自由贸易区不一定
  2. 自由贸易区一定有共同货币
  3. 关税同盟没有内部自由贸易
  4. 二者完全相同
答案与解析

答案：A。层级从低到高常考：优惠贸易安排、自由贸易区、关税同盟、共同市场、经济联盟、完全经济一体化。

25. 贸易创造效应是指？第10章

  1. 高成本国内生产被成员国低成本进口替代
  2. 低成本非成员国进口被高成本成员国进口替代
  3. 所有贸易都消失
  4. 出口补贴增加
答案与解析

答案：A。贸易创造通常提高福利；贸易转移可能降低福利，因为来源从更低成本的非成员国转向较高成本成员国。

26. 资本国际流动后，资本从资本丰裕国流向资本稀缺国的直接原因通常是？第12章

  1. 资本边际收益率差异
  2. 所有国家工资相同
  3. 资本不能移动
  4. 贸易壁垒消失
答案与解析

答案：A。资本会从收益率较低处流向收益率较高处，直到收益率趋于均等。

27. 劳动力国际流动一般会使劳动力流入国工资如何变化？第12章

  1. 下降或受到下行压力
  2. 必然上升
  3. 不可能变化
  4. 变成零
答案与解析

答案：A。劳动力供给增加，工资通常下降；流出国劳动力减少，工资通常上升。注意总福利和不同群体收益不同。

28. 直接标价法下，汇率上升通常表示？第14章

  1. 外币升值、本币贬值
  2. 本币升值、外币贬值
  3. 两种货币都升值
  4. 与币值无关
答案与解析

答案：A。直接标价法是“1单位外币=多少本币”。数字变大，说明买1单位外币要更多本币，本币贬值。

29. 间接标价法下，汇率上升通常表示？第14章

  1. 本币升值
  2. 本币贬值
  3. 外币升值
  4. 进口必然为零
答案与解析

答案：A。间接标价法是“1单位本币=多少外币”。数字变大，说明本币能换更多外币，本币升值。

30. 固定汇率制度下，维持汇率稳定通常需要中央银行？第14章

  1. 干预外汇市场
  2. 完全不持有外汇储备
  3. 取消国际收支账户
  4. 禁止所有商品交易
答案与解析

答案：A。固定汇率不是汇率永远自然不动，而是官方通过买卖外汇等手段维持。

31. 购买力平价理论的基础是一价定律，其核心思想是？第15章

  1. 同一种商品用同一货币表示的价格应趋于一致
  2. 利率永远为零
  3. 汇率只由政府规定
  4. 国际收支永远顺差
答案与解析

答案：A。绝对购买力平价与价格水平有关，相对购买力平价与通货膨胀率差异有关。

32. 抛补利率平价强调投资者通过远期外汇市场规避什么风险？第15章

  1. 汇率风险
  2. 生产风险
  3. 关税风险
  4. 自然资源风险
答案与解析

答案：A。抛补就是用远期合约锁定未来汇率；无抛补则暴露于预期汇率变化。

33. 货币模型中，一国货币供给相对增加，在其他条件不变时通常会导致本币？第15章

  1. 贬值
  2. 升值
  3. 价值不变
  4. 自动变成黄金
答案与解析

答案：A。货币供给增加会提高价格水平或降低货币价值，通常对应本币贬值。第15章记结论即可。

34. 国际收支平衡表采用的记账方法是？第16章

  1. 复式记账
  2. 单式记账
  3. 随机记账
  4. 只记出口不记进口
答案与解析

答案：A。每笔国际经济交易都有借贷两方，所以表面上总是平衡，但可以存在经济意义上的失衡。

35. 国际收支三大账户通常包括经常账户、资本和金融账户以及？第16章

  1. 错误与遗漏账户
  2. 生产可能性账户
  3. 消费者剩余账户
  4. 关税同盟账户
答案与解析

答案：A。教材口径可能有细分，但经常账户、资本和金融账户、错误与遗漏是常见框架。

36. 商品出口收入应记入国际收支的哪一类？第16章

  1. 经常账户贷方
  2. 经常账户借方
  3. 错误与遗漏借方
  4. 官方储备借方
答案与解析

答案：A。出口带来外汇收入，记贷方；进口支付外汇，记借方。

37. 自发账户与调整账户的区分主要用于判断？第16章

  1. 国际收支是否存在经济意义上的失衡
  2. 生产者剩余大小
  3. 比较优势方向
  4. 关税税率高低
答案与解析

答案：A。国际收支表会计上平衡，但自发交易出现差额时，需要由调整性交易弥补，这就是失衡判断的逻辑。

38. 弹性分析法讨论国际收支调整时，重点关注？第17章

  1. 汇率变动对进出口数量和贸易收支的影响
  2. 生产可能性曲线形状
  3. 幼稚产业筛选标准
  4. 配额租金归属
答案与解析

答案：A。第17章不用推导，记各理论关注点和结论。弹性法常和马歇尔-勒纳条件联系。

39. 马歇尔-勒纳条件大意是，本币贬值改善贸易收支需要？第17章

  1. 进出口需求弹性之和足够大
  2. 关税为零
  3. 所有商品价格不变
  4. 资本完全不能流动
答案与解析

答案：A。记结论即可：贬值不一定马上改善贸易收支，要看进出口需求弹性。

40. J曲线效应指的是？第17章

  1. 货币贬值后贸易收支可能先恶化后改善
  2. 关税税率永远呈J形
  3. 生产可能性曲线向内移动
  4. 要素价格完全不变
答案与解析

答案：A。短期数量反应慢，价格效应先出现，所以可能先恶化；长期数量调整后改善。

41. 吸收分析法认为改善国际收支，需要？第17章

  1. 使国内产出相对国内吸收增加
  2. 只画供求图
  3. 只提高配额
  4. 取消所有金融账户
答案与解析

答案：A。基本关系可记为：贸易差额约等于国民收入减国内吸收，即 B = Y - A。

42. 货币分析法强调国际收支失衡本质上是什么失衡？第17章

  1. 货币供求失衡
  2. 生产者剩余失衡
  3. 要素密集度失衡
  4. 关税同盟失衡
答案与解析

答案：A。第17章理论很多，但考试要求通常是记核心结论，不要求推导。

43. 资产组合平衡模型相比简单货币模型，更强调？第15章

  1. 本外币资产不是完全替代，资产供求影响汇率
  2. 只有商品价格影响汇率
  3. 所有资产收益率永远相同
  4. 国际贸易不存在
答案与解析

答案：A。老师说不掌握复杂推导，记简化结论：资产组合、风险偏好和资产供求会影响汇率。

44. 下列哪项最适合作为图形题重点？综合

  1. 关税、倾销、出口补贴
  2. 第11章全部内容
  3. 纯文字章节所有定义
  4. 国际金融复杂模型推导
答案与解析

答案：A。这直接对应老师录音：图形题集中在贸易理论和贸易政策，关税、倾销、出口补贴尤其重要。

二、图形分析题 8题

图形题1：小国进口关税

问题：根据图形分析小国征收进口关税后的价格、生产、消费、进口量和福利变化。

答案与解析

关税使国内价格由 Pw 上升到 Pw+t。国内生产从 Q1 增加到 Q2，国内消费从 Q4 减少到 Q3，进口量从 Q1Q4 减少到 Q2Q3。

福利：消费者剩余下降；生产者剩余上升；政府获得关税收入；本国净福利损失为两个三角形 b+d。小国不能影响世界价格，所以没有贸易条件收益。

图形题2：大国进口关税与最优关税

问题：为什么大国可能存在最优关税，而小国最优关税为0？

答案与解析

大国进口量足以影响世界价格。征收关税后，外国出口价格可能下降，本国获得贸易条件改善收益；但关税也会造成生产扭曲和消费扭曲。

当边际收益等于边际损失时，本国福利最大，对应最优关税 t*。小国不能影响世界价格，没有贸易条件收益，所以征税只有扭曲损失，最优关税为 0。

图形题3：进口配额

问题：进口配额和进口关税的图形为什么相似？关键差异在哪里？

答案与解析

相似点：二者都会使国内价格上升、国内生产增加、国内消费减少、进口减少，都有生产扭曲和消费扭曲。

关键差异：关税收入归政府；配额下中间矩形是配额租金，可能归政府、进口商、外国出口商，也可能在寻租中浪费。因此配额福利结果比关税更不确定。

图形题4：出口补贴

问题：小国实行出口补贴后，国内价格、生产、消费、出口和福利如何变化？

答案与解析

出口补贴使国内价格从 Pw 上升到 Pw+s。生产增加，消费减少，出口量扩大。

生产者剩余增加，消费者剩余减少，政府发生补贴支出。本国净福利下降，损失来自过度生产和过度消费减少带来的扭曲，再加上政府补贴成本。

图形题5：倾销与价格歧视

问题：结合图形说明持续性倾销为什么可能发生，反倾销成立通常要满足什么条件？

答案与解析

持续性倾销常见解释是价格歧视：企业在国内市场定较高价格，在国外市场定较低价格。条件通常包括企业具有市场力量、国内外市场可分割、不同市场需求弹性不同。

反倾销通常要证明三点：存在倾销、国内产业受到实质损害、倾销与损害之间存在因果关系。反倾销税一般不超过倾销幅度。

图形题6：开放经济中的贸易利益

问题：为什么开放经济中生产点P和消费点C可以不同？如何从图上判断贸易利益？

答案与解析

开放经济下，一国可以按比较优势进行生产，再通过国际贸易交换，所以生产点和消费点可以分离。

如果贸易后的消费点 C 位于比封闭经济更高的社会无差异曲线 U2 上，说明社会福利提高，这就是贸易利益。

图形题7：关税同盟的贸易创造与贸易转移

问题：建立关税同盟后，贸易创造和贸易转移分别如何影响福利？

答案与解析

贸易创造：成员国低成本进口替代本国高成本生产，通常提高福利。

贸易转移：原本从非成员国低成本进口，转为从成员国较高成本进口，可能降低福利。关税同盟总福利取决于贸易创造收益和贸易转移损失谁更大。

图形题8：资本国际流动

问题：资本为什么会从资本丰裕国流向资本稀缺国？流动后收益率和福利如何变化？

答案与解析

资本丰裕国资本边际收益率较低，资本稀缺国资本边际收益率较高，所以资本从低收益率地区流向高收益率地区。

流动后两国资本收益率趋于均等，世界总产出提高。但国内不同群体收益不同：资本流出国资本所有者可能受益，使用资本的生产者可能受损；流入国相反。

三、计算题 12题

计算题1：比较优势。A国生产1单位小麦需2小时、1单位布需4小时；B国生产1单位小麦需6小时、1单位布需6小时。判断绝对优势和比较优势。

答案与解析

绝对优势：A国生产小麦2小时<6小时，生产布4小时<6小时，所以A国两种产品都有绝对优势。

比较优势：A国1小麦机会成本=2/4=0.5布；B国1小麦机会成本=6/6=1布。A国小麦机会成本低，有小麦比较优势。A国1布机会成本=4/2=2小麦；B国1布机会成本=6/6=1小麦。B国布机会成本低，有布比较优势。

计算题2：贸易范围。A国1小麦机会成本为0.5布，B国1小麦机会成本为1布。若两国进行贸易，1小麦交换多少布时双方都可能获益？

答案与解析

国际交换比率应位于两国机会成本之间：

0.5布 < 1小麦的国际价格 < 1布

例如1小麦换0.8布，A国出口小麦比国内换0.5布更划算，B国进口小麦比国内用1布成本更低，双方都获益。

计算题3：有效保护率。某产品自由贸易价格为100元，投入品成本为60元。征收关税后，最终产品价格提高到120元，投入品因关税成本提高到66元。求有效保护率。

答案与解析

有效保护率 = (保护后增加值 - 自由贸易增加值) / 自由贸易增加值

自由贸易增加值 = 100 - 60 = 40。保护后增加值 = 120 - 66 = 54。

有效保护率 = (54 - 40) / 40 = 35%。

计算题4：产业内贸易指数。某国汽车出口额为80亿美元，进口额为120亿美元。求该产业的格鲁贝尔-劳埃德指数。

答案与解析

GL = 1 - |X-M| / (X+M)

GL = 1 - |80-120| / (80+120) = 1 - 40/200 = 0.8。

该产业产业内贸易程度较高，指数为0.8。

计算题5：小国关税福利。进口品需求曲线下，关税使生产扭曲损失为6，消费扭曲损失为9，政府关税收入为30。问本国净福利变化是多少？

答案与解析

小国关税的净福利变化只看无谓损失，因为政府收入只是国内转移，消费者损失中有一部分转给政府和生产者。

净福利变化 = -(生产扭曲损失 + 消费扭曲损失) = -(6+9) = -15

本国净福利减少15。

计算题6：大国关税福利。某大国征收进口关税后，贸易条件收益为40，生产扭曲损失为12，消费扭曲损失为18。问本国净福利变化。

答案与解析

大国关税净福利 = 贸易条件收益 - 生产扭曲损失 - 消费扭曲损失

净福利 = 40 - 12 - 18 = 10。本国福利增加10。

但这不代表全球福利增加，因为外国利益受损，且存在扭曲损失。

计算题7：出口补贴。某小国出口补贴使生产者剩余增加50，消费者剩余减少20，政府补贴支出45。求本国净福利变化。

答案与解析

净福利变化 = 生产者剩余增加 - 消费者剩余减少 - 政府补贴支出

净福利 = 50 - 20 - 45 = -15。本国福利减少15。

计算题8：直接标价法换算。人民币对美元汇率为 USD 1 = CNY 7.20。一件美国商品价格为50美元，折合人民币多少？若人民币升值到 USD 1 = CNY 7.00，人民币价格如何变化？

答案与解析

原价格：50 × 7.20 = 360元。

升值后：50 × 7.00 = 350元。

人民币升值后，进口美元商品折合人民币价格下降10元。

计算题9：间接标价法。若 GBP 1 = USD 1.25，一件英国商品价格为80英镑，折合美元多少？

答案与解析

80 × 1.25 = 100美元。

这里虽然给的是英镑对美元，但本质仍是单位换算：商品英镑价格乘以每英镑美元数。

计算题10：远期升贴水。即期汇率 USD 1 = CNY 7.20，三个月远期汇率 USD 1 = CNY 7.28。美元相对人民币是升水还是贴水？三个月升贴水率约为多少？

答案与解析

远期美元价格更高，说明美元远期升水。

三个月升水率 = (7.28 - 7.20) / 7.20 = 1.11%

美元三个月远期升水约1.11%。如果折成年率，约为1.11% × 4 = 4.44%。

计算题11：购买力平价。某商品在中国价格为70元，在美国价格为10美元。按绝对购买力平价，人民币对美元汇率应是多少？

答案与解析

汇率 = 本国价格 / 外国价格

70 / 10 = 7。因此购买力平价汇率为 USD 1 = CNY 7。

计算题12：国际收支记账。中国企业出口商品取得100万美元，货款存入海外银行账户。请说明国际收支中如何记账。

答案与解析

商品出口属于经常账户贷方，记 +100万美元。货款存入海外银行账户，表示本国对外资产增加，记金融账户借方 -100万美元。

复式记账下，两边金额相等、方向相反，会计上平衡。

四、论述题 6题

论述题1：试述最优关税理论，并评价其政策含义。

参考答案框架

先定义：最优关税是使一国福利最大化的关税水平。大国征收进口关税可能压低世界价格，从而改善贸易条件，获得收益；但关税同时造成生产扭曲和消费扭曲。当边际贸易条件收益等于边际扭曲损失时，达到最优关税。

评价：该理论只适用于能影响世界价格的大国，小国最优关税为0。从本国看可能获利，但从全球看会降低资源配置效率，并可能引发贸易报复和贸易战，因此现实政策应谨慎使用。

论述题2：比较进口关税与进口配额的经济效应。

参考答案框架

共同点：二者都会提高国内价格，使国内生产增加、消费减少、进口减少；消费者剩余下降，生产者剩余上升，并产生生产扭曲和消费扭曲。

区别：关税通过价格机制限制进口，政府获得关税收入；配额直接限制进口数量，配额租金归属不确定。若政府拍卖许可证，效果接近关税；若租金被进口商或外国出口商获得，或发生寻租浪费，配额对本国福利更不利。

论述题3：分析出口补贴的经济效应。

参考答案框架

出口补贴使出口商品国内价格上升，刺激国内生产，抑制国内消费，扩大出口。生产者剩余增加，消费者剩余减少，政府承担补贴支出。

对小国而言，出口补贴通常导致本国净福利下降，因为生产者收益不足以弥补消费者损失和政府支出。从全球看，出口补贴扭曲资源配置，也容易引发贸易摩擦。

论述题4：说明H-O理论及其四个相关定理。

参考答案框架

H-O定理：一国出口密集使用其丰裕要素的产品，进口密集使用其稀缺要素的产品。要先区分要素禀赋是国家层面，要素密集度是产品层面。

要素价格均等化定理：在一定条件下，自由贸易会使各国同质要素价格趋于均等。斯托尔珀-萨缪尔森定理：商品价格上升会提高该商品密集使用要素的真实报酬，降低另一要素真实报酬。罗伯津斯基定理：商品价格不变时，某要素增加会使密集使用该要素的产品产量增加，另一产品产量减少。

论述题5：试述关税同盟的静态福利效应。

参考答案框架

关税同盟是成员国之间取消贸易壁垒，并对非成员国实行共同对外关税。其静态福利效应主要包括贸易创造和贸易转移。

贸易创造是成员国低成本产品替代本国高成本生产，提高资源配置效率，通常增加福利。贸易转移是原本从低成本非成员国进口，转向从较高成本成员国进口，可能降低福利。关税同盟最终是否有利，取决于贸易创造收益是否大于贸易转移损失。

论述题6：概述国际收支调整理论的主要观点。

参考答案框架

弹性分析法强调汇率变化通过进出口需求弹性影响贸易收支，常用马歇尔-勒纳条件说明贬值能否改善贸易收支，并存在J曲线效应。

吸收分析法从国民收入和国内吸收角度分析，认为改善国际收支要使产出相对吸收增加。货币分析法认为国际收支失衡本质上是货币供求失衡。考试一般记核心结论，不要求复杂推导。
