1. 必背20句

  1. 比较优势看机会成本，不看绝对生产率；绝对优势看劳动生产率或单位劳动投入。
  2. 封闭经济中生产点=消费点；开放经济中生产点和消费点可以分离。
  3. 消费点到更高的社会无差异曲线，说明贸易提高社会福利。
  4. PPF斜率绝对值是机会成本，也叫边际转换率。
  5. 要素禀赋是国家层面；要素密集度是产品或产业层面。
  6. H-O定理：出口密集使用本国丰裕要素的产品，进口密集使用本国稀缺要素的产品。
  7. 要素价格均等化：自由贸易在严格条件下使同质要素价格趋同。
  8. S-S定理：商品相对价格上升，会提高该商品密集使用要素的真实报酬。
  9. 罗伯津斯基定理：商品价格不变时，某要素增加，使密集使用该要素的产品产量增加，另一产品减少。
  10. 里昂惕夫之谜：美国资本丰裕却被发现出口劳动密集型产品，提示H-O要补充技术、人力资本、需求等因素。
  11. 内部规模经济是企业自身扩大导致平均成本下降；外部规模经济是行业或地区扩大导致成本下降。
  12. 要素禀赋解释产业间贸易；规模经济、产品差异化解释产业内贸易。
  13. 小国最优关税为0，因为不能影响世界价格，征税只有扭曲损失。
  14. 大国关税可能改善贸易条件，但损害外国福利并可能引发报复。
  15. 小国进口关税：价格升，生产增，消费减，进口减，净福利下降。
  16. 进口配额和关税的核心区别是配额租金归属。
  17. 出口补贴：国内价格升，生产增，消费减，出口增；生产者得益，消费者和政府受损。
  18. 倾销是国际市场间价格歧视；反倾销要看倾销、损害、因果关系。
  19. 关税同盟看贸易创造和贸易转移谁大。
  20. 国际收支复式记账会计上平衡，但经济意义上仍可能失衡。

2. 课本/PPT校对后的易错点

这部分是新增校对点。课本OCR和PPT关键词里反复出现的内容，最容易被选择题、判断题偷袭。
第2章：PPF形状机会成本递增：PPF凹向原点；机会成本不变：直线，常用于李嘉图模型；机会成本递减：和规模经济有关。
第2章：贸易利益分解课本强调贸易利益可分为交换利益和专业化利益。图形题只要写“更高无差异曲线”就够稳。
第3章：贸易条件国际交换比例要在两国机会成本之间；越接近本国国内交换比例，本国获利越少。
第4章：特定要素模型短期按部门分利益：出口部门特定要素受益，进口竞争部门特定要素受损；核心原因是部分要素不能跨行业流动。
第6章：GL指数GL=1-|X-M|/(X+M)。越接近1，产业内贸易越强；等于0说明基本是产业间贸易。
第8章：幼稚产业标准穆勒标准看将来能否自立；巴斯塔布尔标准看未来收益能否补偿保护成本；肯普标准看是否存在外部经济。
第9章：有效保护率保护的是国内“增加值”，不是只看名义关税。投入品关税越高，最终品的有效保护越低。
第14章：直接标价法课本和PPT默认常用直接标价法：1单位外币=若干本币；数值上升是外币升值、本币贬值。
第17章：调整理论弹性分析法是价格调整；吸收分析法是收入/支出调整；货币分析法从货币供求看失衡。

4. 图形题：照这个顺序写

市场类型 -> 价格变化 -> 生产/消费/贸易量变化 -> CS/PS/政府/租金 -> 净福利

小国进口关税图

考场句：国内价格上升，生产增加，消费减少，进口减少；消费者剩余下降，生产者剩余增加，政府获得关税收入；两个三角形是净损失，小国净福利下降。

出口补贴、进口配额、倾销怎么写

出口补贴：国内价格上升，生产增加，消费减少，出口增加。生产者剩余增加，消费者剩余减少，政府支付补贴，小国净福利通常下降。

进口配额：限制数量导致国内价格上升。与关税相似，但配额租金归属不确定；若租金归外国出口商或寻租耗散，本国损失更大。

倾销：重点不是剩余图，而是“价格歧视”：企业有市场力量、国内外市场分割、需求弹性不同。反倾销看倾销、损害、因果关系，税额一般不超过倾销幅度。

5. 计算题最后公式

比较优势工时题：1单位X机会成本 = aLX / aLY。机会成本低，出口该产品。
贸易范围国际交换比率在两国机会成本之间；等于边界，一方无额外利益。
有效保护率ERP=(保护后增加值-自由贸易增加值)/自由贸易增加值。
产业内贸易GL=1-|X-M|/(X+M)。
关税福利小国净福利 = -(生产扭曲+消费扭曲)。大国净福利 = 贸易条件收益-两个扭曲。
直接标价法USD1=CNY7.20变7.50：美元升值，人民币贬值。
购买力平价绝对PPP：汇率=本国价格/外国价格。相对PPP：通胀高的货币倾向贬值。
国际收支出口贷方，进口借方；对外资产增加记借方，对外资产减少记贷方。

6. 论述题：最像会出的题

选择顺序：贸易保护 > H-O四定理 > 第9章政策比较 > 关税同盟 > 国际收支调整。汇率理论作为备选。
题1：贸易保护政策的理论依据及局限最高

题目变体：为什么现实中存在贸易保护？最优关税、幼稚产业、战略性贸易政策如何评价？

自由贸易基准 -> 最优关税 -> 幼稚产业 -> 战略性贸易政策 -> 政治经济学 -> 局限

考场可写：贸易保护政策是在自由贸易之外，政府通过关税、配额、补贴等手段限制进口或扶持出口。自由贸易通常能提高资源配置效率，但现实中仍存在若干保护理由。

第一，最优关税理论认为，大国如果能影响世界价格，适度进口关税可能压低进口品世界价格，改善本国贸易条件。但关税也会造成生产扭曲和消费扭曲，且小国不能影响世界价格，所以小国最优关税为0。

第二，幼稚产业保护理论认为，新兴产业当前竞争力不足，但经过暂时保护和学习积累，未来可能形成比较优势。穆勒标准看保护后能否自立，巴斯塔布尔标准看未来收益能否补偿保护成本，肯普标准看是否存在外部经济。

第三，战略性贸易政策强调，在不完全竞争和规模经济行业中，政府干预可能帮助本国企业争夺超额利润。政治经济学还说明，贸易保护可能来自利益集团、投票压力和收益成本分布不均。

但是，贸易保护会造成效率损失、寻租、信息不完全、外国报复和保护固化。因此，贸易保护有一定理论依据，但应临时、透明、有条件，不能否定自由贸易的基本效率优势。

题2：H-O理论及相关定理，并评价解释力最高

题目变体：说明要素禀赋理论；说明四大定理；解释里昂惕夫之谜。

要素禀赋/密集度 -> H-O -> FPE -> S-S -> 罗伯津斯基 -> 里昂惕夫之谜 -> 评价

考场可写：H-O理论又称要素禀赋理论，从各国要素相对丰裕程度差异解释贸易模式。要素禀赋是国家层面的概念，指一国资本、劳动等要素的相对丰裕程度；要素密集度是产品或产业层面的概念，指某产品生产中相对密集使用哪种要素。

H-O定理认为，一国倾向于出口密集使用本国相对丰裕要素的产品，进口密集使用本国相对稀缺要素的产品。例如资本丰裕国出口资本密集型产品，劳动丰裕国出口劳动密集型产品。

要素价格均等化定理认为，在严格条件下，自由贸易会使不同国家同质要素价格趋于均等。斯托尔珀-萨缪尔森定理说明，某商品价格上升会提高该商品密集使用要素的真实报酬，降低另一要素真实报酬。罗伯津斯基定理说明，在商品价格不变时，某种要素增加会使密集使用该要素的产品产量增加，并使另一产品减少。

H-O理论解释了要素禀赋差异如何形成贸易模式，也能分析贸易对收入分配的影响。但里昂惕夫之谜表明，现实贸易不总与传统预测一致，原因可能包括技术、人力资本、需求偏好、自然资源和贸易壁垒等。因此，H-O理论很重要，但需要结合其他因素解释现实贸易。

题3：比较进口关税、进口配额和出口补贴很高

三者都是贸易政策工具，会改变国内价格和资源配置。进口关税对小国而言使国内价格上升，生产增加、消费减少、进口减少；消费者剩余下降，生产者剩余上升，政府获得关税收入，但存在生产扭曲和消费扭曲，净福利下降。

进口配额直接限制进口数量，效果与等额关税相似，也会提高国内价格、增加生产、减少消费。关键差别是配额租金归属不确定：政府拍卖时接近关税；若租金归外国出口商或被寻租耗散，本国损失更大。

出口补贴使出口部门国内价格上升，生产增加、消费减少、出口扩大。生产者受益，消费者受损，政府支付补贴。小国情况下，生产者收益通常不足以弥补消费者损失和财政支出，因此净福利下降。

题4：关税同盟的静态与动态效应高

关税同盟是成员国之间取消贸易壁垒，同时对非成员国实行共同对外关税。静态效应主要包括贸易创造和贸易转移。

贸易创造是本国高成本生产被成员国低成本进口替代，能提高资源配置效率，通常增加福利。贸易转移是原本从低成本非成员国进口，转向从较高成本成员国进口，可能降低福利。

因此，关税同盟是否有利，取决于贸易创造收益是否大于贸易转移损失。还可补充动态效应：扩大市场、形成规模经济、增强竞争、促进投资和技术进步。

题5：国际收支失衡及调整理论可选

国际收支是一国居民与非居民在一定时期内全部经济交易的系统记录。复式记账使国际收支表在会计意义上总是平衡，但这不等于经济意义上没有失衡，因为自发性交易可能需要储备资产变动或借款来弥补。

判断失衡要区分自发账户和调整账户。若自发账户持续逆差，需要通过官方储备或对外借款弥补，就说明经济上存在国际收支失衡。

弹性分析法强调汇率通过进出口需求弹性影响贸易收支，本币贬值能否改善贸易收支取决于马歇尔-勒纳条件，即进出口需求弹性绝对值之和大于1，并可能出现J曲线效应。吸收分析法认为B=Y-A，改善收支要增加产出或减少国内吸收。货币分析法认为失衡与货币供求失衡有关。结构分析法强调长期失衡可能来自产业结构和供给能力问题。

题6：资本和劳动力国际流动比较可选

资本和劳动力国际流动的共同基础是各国要素回报率差异。资本从低收益率地区流向高收益率地区，劳动力从低工资地区流向高工资地区，流动后回报趋于均等，并可能提高世界总产出。

但收益不是平均分配的。资本流动会影响资本所有者和劳动者收入，劳动力流动会影响移民、流入国劳动者、流出国劳动者和企业。劳动力流动还涉及移民政策、社会融合、脑流失等问题。因此，要素流动总体可能提高效率，但会带来收入分配和社会政策问题。

题7：绝对优势与比较优势基础

绝对优势理论由亚当斯密提出，判断标准是劳动生产率更高或单位劳动投入更少。比较优势理论由李嘉图提出，判断标准是机会成本更低。

二者都说明专业化分工和自由贸易可以带来利益。区别在于，绝对优势解释“谁更有效率”，比较优势解释“谁相对更划算”。比较优势理论更强，因为即使一国在所有产品上都强或都弱，只要机会成本不同，仍然存在互利贸易。

局限是古典模型假设简单，主要考虑劳动一种生产要素，没有充分解释要素禀赋、规模经济、不完全竞争和收入分配问题。

题8：汇率决定理论主要观点备选

购买力平价理论以一价定律为基础，认为长期汇率由两国价格水平决定，通胀较高国家货币长期倾向贬值。

利率平价理论强调利率差异与汇率之间的关系。抛补利率平价联系利差和远期汇率升贴水；无抛补利率平价联系利差和预期未来即期汇率变化。

货币模型从货币供求角度解释汇率，认为货币供给、价格水平、收入和利率会影响汇率。资产组合平衡模型进一步强调不同资产的供求、风险和收益共同影响汇率。本课程只需掌握核心结论，不需要复杂推导。

7. 最后一分钟

论述题开头：该问题可以从概念、作用机制、福利影响和政策评价四个方面分析。

政策题中间：消费者剩余、生产者剩余、政府收入或支出、社会净福利。

理论题中间：基本假设、核心结论、相关定理、现实局限。

评价题结尾：该理论或政策有一定解释力和适用价值，但现实中还要考虑效率损失、分配效应、信息不完全和政策执行问题。

最稳三题：贸易保护政策；H-O理论及相关定理；进口关税、进口配额和出口补贴比较。
