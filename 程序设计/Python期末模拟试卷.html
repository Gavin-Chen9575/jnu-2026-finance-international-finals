四、简答题参考与评分点

1. 列表与元组（5 分）

列表用方括号，内容和长度可修改；元组用圆括号（圆括号在许多场合可省），元组容器创建后不可修改。两者都是有序序列，都支持索引、切片和 in。单元素列表写 [3]；单元素元组必须写 (3,)。

评分：可变性 2 分，表示方式 1 分，共同点 1 分，单元素写法 1 分。

2. 文件模式（5 分）

r 只读，文件不存在报错，不清空；w 只写，不存在则创建，存在则先清空；a 追加写，不存在则创建，已有内容保留且写入末尾；+ 与 r/w/a 合用，在原功能上增加读写能力，但是否清空/追加仍由主模式决定。

评分：r/w/a 各 1 分，+ 1 分，创建/清空边界完整 1 分。

3. 程序阅读（5 分）

输出 ['b','c','a']。函数遍历字符串；若字符已出现就先从结果列表删除，再追加到末尾，因此最后保留每个字符一次，并按其“最后一次出现”的先后顺序排列。

评分：输出 2 分，删除含义 1 分，追加含义 1 分，整体功能 1 分。

4. 死循环纠错（5 分）

randint(1,10) 最多只能产生 10 个不同整数，集合长度永远达不到 20，因此循环无法结束。最小修改为 result.add(randint(1,35))。

评分：指出最多 10 个 2 分，说明长度达不到 20 1 分，正确修改 2 分。

五-1. 完整函数设计参考答案
def score_report(scores):
    average = sum(scores) / len(scores)
    above = []
    for score in scores:
        if score > average:
            above.append(score)
    return average, above

data = [78, 92, 66, 85, 99]
avg, high = score_report(data)
print("平均分：{:.2f}".format(avg))
print("高于平均分：", high)

输出平均分 84.00，高于平均分列表为 [92,85,99]。

评分建议：函数签名 1 分；平均值 2 分；正确遍历筛选 3 分；不修改原列表 1 分；正确返回 1 分；主程序调用与格式化 2 分。
五-2. 程序补空参考答案

① lower()　② 'a' <= ch <= 'z'　③ get　④ items　⑤ reverse=True

def letter_ranking(text):
    counts = {}
    for ch in text.lower():
        if 'a' <= ch <= 'z':
            counts[ch] = counts.get(ch, 0) + 1
    result = list(counts.items())
    result.sort(key=lambda item: item[1], reverse=True)
    return result

输入 "Aba C" 时，返回 [('a',2),('b',1),('c',1)]。次数相同的 b、c 保持首次插入顺序。

评分建议：每空 1.5 分，共 7.5 分；结果 1.5 分；能说明忽略大小写/只统计字母 1 分。
