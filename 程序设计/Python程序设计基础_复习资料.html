02 · ERROR ALERT

提纲中必须纠正的 3 个点

这些不是小细节。以下按 Python 标准语义整理；原提纲扫描页中的相关说法疑似笔误或概念混用。

① open 默认是 "r"

open("a.txt") 等价于只读文本模式 open("a.txt","r")，不是 "r+"。文件不存在会报错。

② copy() 是浅拷贝

b=a.copy() 或 b=a[:] 创建新外层列表，但嵌套的可变元素仍共享引用。真正的深拷贝用 copy.deepcopy(a)。

③ 集合 ^ 是对称差

A ^ B 得到只属于其中一个集合的元素，不是通常意义上的“补集”。差集是 A-B。

03 · BASICS

基础语法、类型与运算

运行与导入

  • 常见运行方式：交互式（逐句执行）和文件式（保存为 .py 后整体执行）。
  • import math 后用 math.sqrt(9)。
  • from math import sqrt 后直接用 sqrt(9)。
import math
from random import randint
print(math.sqrt(16), randint(1, 6))

标识符与赋值

  • 变量名可含字母、数字、下划线，不能以数字开头，不能是关键字，区分大小写。
  • 变量必须先赋值后使用。
  • 链式赋值：a=b=c=2；解包：a,b,c=[2,7,3]。
  • 交换：a,b=b,a，无需临时变量。

常见类型

类别类型可变性要点
数值int float complex不可变/ 真除；// 整除；** 乘方；% 求余
逻辑bool不可变True、False；逻辑运算 not and or
序列str list tuple列表可变，其余不可变支持索引、切片、遍历（集合/字典不是序列）
映射dict可变键唯一且必须可哈希，按键访问
集合set可变元素唯一、无序，元素必须可哈希

转换、输入输出与比较

转换

int("300") 可行；int("3.1") 报错；float("3.13e3") 得 3130.0；eval("8+2**3") 得 16。

字符编码

chr(97) 得 'a'；ord('b') 得 98。字符串按 Unicode 编码逐字符比较。

浮点误差

不要用 0.1+0.2==0.3 判断近似相等。用 abs(a-b)<1e-9 或 math.isclose()。

优先级：大体记作数学运算 > 比较/成员/身份运算 > not > and > or。不确定时加括号。
04 · FLOW CONTROL

顺序、选择、循环

三种基本结构

顺序结构、选择结构、循环结构。Python 没有 do...while；可用 while True 配合 break 模拟“至少执行一次”。

分支

单分支 if、双分支 if...else、多分支 if...elif...else。条件表达式：x if condition else y。

循环

for 适合遍历或次数已知；while 由条件控制。break 结束循环，continue 跳过本次。

# 多分支
score = int(input())
if score >= 90:
    grade = "A"
elif score >= 60:
    grade = "及格"
else:
    grade = "不及格"

# 条件表达式
print("偶数" if n % 2 == 0 else "奇数")

range() 与循环 else

表达式产生的整数
range(5)0, 1, 2, 3, 4
range(2,6)2, 3, 4, 5
range(5,0,-2)5, 3, 1
循环的 else 在循环“正常结束”时执行；若因 break 退出则不执行。continue 不会阻止最终执行 else。
05 · STRING

字符串、索引与切片

s[m:n:d]：从 m 开始，到 n 之前结束，步长为 d

字符串是不可变对象。任何“修改”字符串的方法都返回新字符串，原字符串不变。

操作/方法作用示例结果
s[0] / s[-1]正向/反向索引"Python"[-1] → "n"
s[1:5:2]切片，右端不含"Python"[1:5:2] → "yh"
upper/lower大小写转换返回新字符串
split(sep)分割返回列表
replace(old,new)替换返回新字符串
find/index查找find 找不到返回 -1；index 报错
count计数返回出现次数
format格式化"{:.2f}".format(3.1415)
s = "abcdbbefbbbg"
print(s.split("b"))
print(s.replace("b", ""))
print(s[::-1])      # 逆序
06 · ALGORITHM

迭代、枚举、递归与 random

迭代三要素

  1. 迭代初值
  2. 迭代关系式
  3. 迭代终止条件

例：阶乘中初值 fac=1，关系式 fac*=i，终止由 range(1,n+1) 控制。

枚举法

把可能情况逐一测试，筛选满足条件的结果。应用题常见：百钱买百鸡、数字组合、整除问题。

递归两要素

  1. 递归出口
  2. 递归步骤（规模变小）

缺出口会无限递归；递归调用必须逐步接近出口。

def fib(n):
    if n == 1 or n == 2:   # 递归出口
        return 1
    return fib(n-1) + fib(n-2) # 递归步骤

random 高频函数

函数范围/作用
random.random()[0.0, 1.0)
random.randint(a,b)[a, b]，两端都包含
random.randrange(b)从 range(b) 中随机取值，即 0 到 b-1
random.sample(seq,k)无放回抽取 k 个元素，返回列表
07 · FUNCTIONS

函数、参数、作用域与 lambda

概念规则
位置参数按顺序对应；调用时通常放在关键字参数之前
关键字参数按形参名传递，如 f(3, c=8)；同一参数不能重复赋值
默认值参数定义时一般放在无默认值参数之后
*args收集额外位置实参为元组
**kwargs收集额外关键字实参为字典
返回值无 return 或只写 return 时返回 None；可返回任意类型
def volume(width, height=5, length=8):
    return width * height * length

print(volume(3))
print(volume(3, length=10))

f = lambda x, y: x - y
print(f(8, 3))

作用域

函数内赋值的名字通常是局部变量，函数外定义的是全局变量。函数内部读取同名变量时按局部优先；需要在函数内修改全局变量时使用 global。

参数可变性

传入可变对象（如列表）并修改其内容，调用者可看到变化；给形参重新绑定新对象，不会让外部变量也改绑。

08 · SEQUENCES

列表、元组、生成式与复制

操作是否修改原列表说明
append(x)是把 x 作为一个元素追加
extend(iterable)是逐个追加可迭代对象中的元素
insert(i,x)是在位置 i 插入
remove(x)是删除第一个值为 x 的元素，找不到报错
pop([i])是删除并返回元素，默认最后一个
sort()是原地排序，返回 None
sorted(x)否返回新列表
+、*否产生新列表
nums = [3, 5, 8]
nums.append([1, 2])  # [3,5,8,[1,2]]
nums = [3, 5, 8]
nums.extend([1, 2])  # [3,5,8,1,2]

squares = [i*i for i in range(1, 11) if i % 2 == 0]

浅拷贝图景

写法外层是否同一对象嵌套可变元素是否共享
b=a是是
b=a.copy() / a[:]否是（浅拷贝）
b=copy.deepcopy(a)否否（深拷贝）
元组：元组本身不可变，因此没有 append/extend/insert/remove/pop 等修改方法；但元组中的可变元素（如列表）内部仍可修改。单元素元组要写成 (3,)。
09 · DICT & SET

字典与集合

字典

  • 键唯一且必须可哈希（通常用数值、字符串、元组），值可为任意类型。
  • d[key] 找不到会报错；d.get(key,default) 返回默认值。
  • key in d 判断的是键。
  • keys()、values()、items() 分别遍历键、值、键值对。
  • update() 合并字典，同名键被新值覆盖。
counts = {}
for ch in "banana":
    counts[ch] = counts.get(ch, 0) + 1

for k, v in counts.items():
    print(k, v)

集合

  • 无序、元素唯一；适合去重与成员判断。
  • set() 是空集合；{} 是空字典。
  • add(x) 加一个元素；update(iterable) 加多个。
  • remove(x) 不存在时报错；discard(x) 不存在也不报错。
运算含义
A & B交集
A | B并集
A - B差集
A ^ B对称差
10 · FILES

文件、CSV 与异常

模式可读可写不存在原内容
r✓×报错保留
r+✓✓报错保留，指针起始在开头
w×✓新建清空
w+✓✓新建清空
a×✓新建保留，写入追加到末尾
a+✓✓新建保留，写入追加到末尾

读取

read()：读内容为字符串；readline()：读一行为字符串；readlines()：读多行为字符串列表。

写入

write(s) 写一个字符串；writelines(seq) 写一组字符串，不会自动添加换行。

文件指针

读完后指针在文件末尾，再读通常为空。用 seek(0) 回到开头。

with open("data.txt", "r", encoding="utf-8") as f:
    text = f.read()

try:
    n = int(input())
except ValueError:
    print("输入不是整数")
else:
    print("平方为", n*n)
finally:
    print("无论是否异常都会执行")

CSV

csv.reader(f) 每次迭代得到一行列表；writer.writerow(row) 写一行；writer.writerows(rows) 写多行。Windows 写 CSV 常用 newline="" 避免空行。

11 · FINAL CHECK

考前 15 分钟速记

边界

  • 切片和 range 都是“左含右不含”
  • randint(a,b) 两端都含
  • 索引越界报错，切片越界通常不报错

返回值

  • list.sort() 返回 None
  • sorted() 返回新列表
  • 无 return 的函数返回 None

可变性

  • 可变：列表、字典、集合
  • 不可变：数值、布尔、字符串、元组
  • 元组内可包含可变对象

高频区别

  • break vs continue
  • append vs extend
  • find vs index
  • remove vs discard
应用题通用答题模板
  1. 明确输入数据与输出要求。
  2. 给变量初始化（计数器、累加器、最值等）。
  3. 选择循环或递归，写清终止条件。
  4. 在循环内判断并更新状态。
  5. 输出结果，检查空数据、0、负数、边界值。
简答题通用表达

先给定义，再列 2-3 个特征，最后用一句对比或代码例子收束。例如问“列表与元组的区别”：二者都是序列，都支持索引、切片和遍历；列表可变且有多种原地修改方法，元组不可变；列表用方括号，元组通常用圆括号。
