1. 程序和代码怎么读

必须懂程序就是一组按规则写好的指令。正常情况下，Python 从上到下执行；碰到分支会选择路线，碰到循环会重复，碰到函数调用会进入函数。

最小程序

name = "小王"
score = 82
print(name, score)

第 1 行保存名字，第 2 行保存成绩，第 3 行把两者输出。

小王 82

四类最常见语句

  • 赋值：x = 3，把 3 保存到名字 x 中。
  • 输入输出：input() 接收输入，print() 输出。
  • 控制：if 决定做不做，for/while 决定重复几次。
  • 函数：def 把一段功能打包并起名字。

缩进不是美观问题，而是语法

age = 20
if age >= 18:
    print("成年人")     # 前面四个空格：属于 if
print("程序结束")       # 没有缩进：不属于 if

冒号 : 后面通常会出现缩进块。考试里最常见的是 4 个空格；同一层必须对齐。

小检查：如果 age 改成 16，会输出什么？

只输出 程序结束。因为条件 16 >= 18 为假，缩进的那一行不执行。

注释：# 后的内容是给人看的说明，Python 不执行。例如 x = 3 # 保存数字3。

2. 变量、类型、输入输出

2.1 变量：贴在数据上的名字

x = 10
x = x + 3
print(x)   # 13

= 不是数学中的“永远相等”，而是把右边算出的结果交给左边。第二行先取出旧的 x=10，加 3，再把 13 存回 x。

最常见混淆：= 是赋值；== 才是“是否相等”的比较。

2.2 四种必须认识的类型

类型含义例子转换函数
int整数3、-10int("12") → 12
float小数3.14、-0.5float("3.5") → 3.5
str字符串/文本"hello"、"12"str(12) → "12"
bool真假值True、Falsebool(x)

"12" 和 12 不一样：前者是两个字符组成的文本，后者是可以参与数值计算的整数。

2.3 输入永远先得到字符串

age = input("请输入年龄：")
print(type(age))              # <class 'str'>

age = int(input("请输入年龄："))
print(age + 1)

如果用户输入 20，最后输出 21。要计算，就先用 int() 或 float() 转换。

多个值输出

name = "小李"
score = 90
print(name, score)

默认用空格分隔，输出 小李 90。

保留两位小数

x = 3.14159
print("{:.2f}".format(x))

输出 3.14。

小检查：为什么 "10" + "2" 得到 "102"？

两个操作数都是字符串，+ 表示拼接。若要得到 12，应写 int("10") + int("2")。

3. 运算符与表达式

表达式就是“能算出一个结果的写法”。先算括号，再按运算优先级计算。

符号作用例子与结果
+ - * /加减乘除7 / 2 → 3.5
//整除7 // 2 → 3
%余数7 % 2 → 1
**乘方2 ** 3 → 8
== != > < >= <=比较5 >= 3 → True
and两个条件都真才真age>=18 and age<=60
or至少一个条件为真x==0 or x==1
not真假取反not True → False
in是否属于"a" in "cat" → True

判断奇偶

n = 13
print(n % 2 == 0)

13 除以 2 余 1，所以输出 False。偶数条件是 n % 2 == 0。

拆数字

n = 347
ge = n % 10
shi = n // 10 % 10
bai = n // 100

个位 7、十位 4、百位 3。

常用优先级：括号 → 乘方 → 乘除/整除/余数 → 加减 → 比较 → not → and → or。拿不准就加括号。

小检查：8 + 2 * 3 和 (8 + 2) * 3 分别是多少？

前者先乘法，得到 14；后者先括号，得到 30。

4. 字符串与切片

必须懂字符串就是一串字符。字符位置从 0 开始编号，负数从右向左编号。

s = "PYTHON"
#     012345

print(s[0])      # P
print(s[-1])     # N
print(s[1:4])    # YTH
print(s[::-1])   # NOHTYP
切片口诀：s[开始:结束:步长]，包含开始、不包含结束，即“左闭右开”。省略步长时默认是 1。
写法作用注意
len(s)长度返回整数
s.lower() / s.upper()转小写/大写返回新字符串
s.find(x)查找位置找不到返回 -1
s.count(x)统计次数返回整数
s.split(",")按逗号拆分返回列表
"-".join(items)用 - 连接字符串元素元素必须都是字符串
s.replace("a","A")替换返回新字符串
s.strip()去两端空白不去中间空白
字符串不可修改：s[0] = "A" 会报错。s.upper() 也不会改变原来的 s，除非写成 s = s.upper()。
小检查：s="abcdef"，s[1:5:2] 是什么？

从下标 1 开始，到 5 之前结束，每次走 2 步：取下标 1、3，结果是 "bd"。

5. if 分支：让程序作选择

if 后的条件只能得到真或假。真就执行对应缩进块，假就跳过。

score = 82

if score >= 90:
    level = "A"
elif score >= 80:
    level = "B"
elif score >= 60:
    level = "C"
else:
    level = "D"

print(level)     # B

多分支从上到下判断，遇到第一个为真的分支后，后面不再判断。因此区间题通常从高到低写。

判断正负

if x > 0:
    print("正数")
elif x == 0:
    print("零")
else:
    print("负数")

判断闰年

if year % 400 == 0 or (
    year % 4 == 0 and year % 100 != 0
):
    print("闰年")
else:
    print("平年")
小检查：上面的成绩程序中 score=95 会输出什么？score=59 呢？

95 输出 A；59 前三个条件都为假，进入 else，输出 D。

6. for / while 循环：重复执行

6.1 for：重复次数或范围较明确

for i in range(1, 5):
    print(i)

range(1, 5) 产生 1、2、3、4，不包含 5。循环每次把一个数交给 i。

写法产生的整数
range(5)0, 1, 2, 3, 4
range(2, 6)2, 3, 4, 5
range(1, 8, 2)1, 3, 5, 7

累加模板

total = 0
for i in range(1, 6):
    total = total + i
print(total)       # 1+2+3+4+5 = 15

6.2 while：只要条件为真就继续

n = 3
while n > 0:
    print(n)
    n = n - 1
print("结束")
3
2
1
结束
while 防死循环：循环体里必须有机会让条件变成假。上例的 n = n - 1 不能漏。

6.3 break 与 continue

语句效果记忆
break立刻结束整个循环“循环到此为止”
continue跳过本轮剩余语句，进入下一轮“这一次不做，后面继续”
 
for i in range(1, 6):
    if i == 3:
        continue
    print(i)

输出 1、2、4、5，只有 i=3 的这一轮被跳过。

小检查：把 continue 换成 break，会输出什么？

输出 1、2。i 等于 3 时直接结束整个循环，4 和 5 不再出现。

7. 函数：把功能打包

应用题核心函数像一台小机器：给它输入（参数），它进行处理，再用 return 交回结果。

def add(a, b):       # 定义函数；a、b 是参数
    result = a + b
    return result    # 把结果交回调用处

x = add(3, 5)        # 调用函数；3、5 是实参
print(x)             # 8
调用 add(3,5)→ a=3, b=5→ 计算 8→ return 8

只打印

def show_sum(a, b):
    print(a + b)

只是把结果显示出来，没有主动交回结果。

返回结果

def get_sum(a, b):
    return a + b

可写 x = get_sum(2,3)，继续使用返回值。

考试最常用的函数模板

def is_even(n):
    if n % 2 == 0:
        return True
    else:
        return False

# 可简写成：
def is_even(n):
    return n % 2 == 0
  • 默认参数：def power(x, n=2)，不传 n 时使用 2。
  • 关键字参数：power(n=3, x=2)，按名字传值。
  • 多个返回值：return minimum, maximum，调用时可写 lo, hi = f(data)。
  • 局部变量：函数内部新建的普通变量通常只能在函数内部使用。
小检查：下面函数 f(4) 返回什么？
def f(n):
    return n * n

print(f(4))

返回并输出 16。

8. 列表、元组、字典、集合

这四种结构都能保存多个数据，但规则不同。先记住最核心区别。

类型示例特点如何取值
列表 list[80, 90, 75]有顺序、可修改、可重复按下标：a[0]
元组 tuple(80, 90, 75)有顺序、不可修改按下标：t[0]
字典 dict{"name":"小王","score":90}键 → 值的对应关系按键：d["score"]
集合 set{1, 2, 3}无重复、无下标通常遍历或做集合运算

8.1 列表：程序题出现最多

scores = [80, 95, 70]
scores.append(88)        # 末尾增加
scores[0] = 82           # 修改第一个
print(len(scores))       # 4
print(sum(scores))       # 335
操作含义
a.append(x)把一个元素 x 加到末尾
a.extend(items)把多个元素逐个加到末尾
a.insert(i,x)在下标 i 前插入 x
a.remove(x)删除第一个值为 x 的元素
a.pop()删除并返回末尾元素
a.sort()原地排序，返回值是 None
sorted(a)返回新排序列表，原列表不变

筛选模板

data = [3, 8, 5, 10]
result = []
for x in data:
    if x % 2 == 0:
        result.append(x)
print(result)            # [8, 10]

8.2 字典：按键查值、做频次统计

student = {"name": "小王", "score": 90}
print(student["name"])          # 小王
print(student.get("age", 0))    # 没有 age，返回默认值 0

字符计数模板

counts = {}
for ch in "abaca":
    counts[ch] = counts.get(ch, 0) + 1
print(counts)                   # {'a': 3, 'b': 1, 'c': 1}

读法：取出 ch 原来的次数；没有就当 0；加 1 后存回。

8.3 元组与集合只先掌握这些

  • 单元素元组必须带逗号：(3,)；(3) 只是整数 3。
  • 空集合必须写 set()；{} 是空字典。
  • 集合会自动去重：set([1,1,2]) 得到含 1、2 的集合。
  • 集合运算：交集 &、并集 |、差集 -、对称差 ^。
小检查：a=[1,2]，执行 a.append([3,4]) 后是什么？

结果是 [1, 2, [3, 4]]，因为 append 把整个列表当成一个元素。若想得到 [1,2,3,4]，用 a.extend([3,4])。

9. 文件与异常

9.1 文件操作三步

打开 open→ 读取 / 写入→ 关闭 close

推荐用 with，离开缩进块时自动关闭文件：

with open("data.txt", "r", encoding="utf-8") as f:
    content = f.read()
print(content)
模式作用文件不存在时原内容
r读取报错保留
w写入创建先清空
a追加创建保留，从末尾写
b二进制模式与 r/w/a 组合如 rb、wb
  • read()：读取全部内容。
  • readline()：读取一行。
  • readlines()：读取全部行，返回列表。
  • write(s)：写一个字符串。
  • writelines(items)：写多个字符串，不会自动添加换行。

9.2 异常：程序运行时出现的问题

try:
    n = int(input("请输入整数："))
    print(10 / n)
except ValueError:
    print("输入不是整数")
except ZeroDivisionError:
    print("不能除以零")
else:
    print("计算成功")

try 中发生对应异常，就进入相应 except；没有异常才执行 else。

小检查：用 w 模式打开已有文件，最危险的地方是什么？

打开时会先清空原内容。只想在末尾增加内容时应使用 a。

10. 程序阅读四步法

代码题不要靠“感觉”。把每次赋值后的变量写下来，答案会自己出现。
  1. 圈输入和初值：哪些变量一开始是什么？
  2. 标出循环范围：range 到底产生哪些数？
  3. 每轮更新变量表：特别关注累加器、列表和计数器。
  4. 最后才看 print：它在循环内还是循环外？输出的是值还是返回值？

示例：逐轮计算

total = 0
for i in range(1, 5):
    if i % 2 == 0:
        total = total + i
print(total)
轮次ii 是否为偶数total 变化
11否0
22是0 → 2
33否2
44是2 → 6

循环结束后才执行 print(total)，所以只输出一次 6。

看到函数时再加两步

  • 把实参代入形参：例如 f(3) 就在函数内先写 n=3。
  • 碰到 return 立即停止本次函数，返回调用处。
自己追踪：下面输出什么？
x = 1
for i in range(3):
    x = x * 2
print(x)

range(3) 循环 3 次。x 依次为 1→2→4→8，最后输出 8。

11. 零基础常见报错

报错常见原因例子怎么想
SyntaxError语法写法不合法漏冒号、括号没配对、位置参数放在关键字参数后程序根本无法开始运行
IndentationError缩进错误if/for/def 后没有正确缩进先检查对齐
NameError名字不存在变量没赋值、拼写错误检查是否“先定义后使用”
TypeError类型不适合该操作"3" + 2字符串和整数不能直接相加
ValueError类型形式对，但值无法转换int("3.5")"3.5" 不是整数字符串
IndexError下标越界[1,2][2]长度 2 的列表只有下标 0、1
KeyError字典中没有该键d["age"]不确定时用 d.get("age")
ZeroDivisionError除数为零10 / 0除法、整除、取余都要防 0
考试做题顺序：先看是否语法错误，再看运行时是否报错，最后才计算输出。不要看到 print 就急着选数字答案。

= 是赋值，== 是比较是否相等。

x = 5
if x > 3:
    print("A")
else:

答案

输出 A。

7. 下面程序输出什么？
total = 0
for i in range(1, 4):
    total += i
print(total)
答案

1+2+3=6，输出 6。

8. break 和 continue 的区别是什么？
答案

break 结束整个循环；continue 只跳过本轮剩余语句。

9. def f(x): return x + 1，那么 f(4) 是多少？
答案

5。

10. 执行 a=[1,2]; a.append(3) 后 a 是什么？
答案

[1, 2, 3]。

11. 空字典和空集合分别怎么写？
答案

空字典 {}；空集合 set()。

12. 在字典 d={"a":10} 中，"a" in d 是真还是假？
答案

真。对字典使用 in 判断的是键。

13. 文件模式 w 和 a 的核心区别是什么？
答案

w 会先清空原文件；a 保留原内容并从末尾追加。

14. int("3.5") 会得到什么？
答案

发生 ValueError。可以先用 float("3.5") 得到 3.5。

15. 下面程序输出什么？
def count_even(data):
    count = 0
    for x in data:
        if x % 2 == 0:
            count += 1
    return count

print(count_even([1, 2, 4, 7]))
答案

列表中有 2、4 两个偶数，函数返回并输出 2。

附录：符号与术语速查

常见符号

  • ()：调用函数、改变运算顺序
  • []：列表、下标、切片
  • {}：字典或非空集合
  • :：引出缩进块，也用于切片
  • ,：分隔多个元素或参数
  • #：单行注释

常见术语

  • 下标/索引：元素的位置编号
  • 遍历：把元素逐个访问一遍
  • 迭代：循环的一轮
  • 形参：函数定义中的参数名
  • 实参：函数调用时传入的实际值
  • 返回值：函数用 return 交回的结果
