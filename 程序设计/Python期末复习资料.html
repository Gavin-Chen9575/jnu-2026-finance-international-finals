第 1 章　计算机基础及 Python 简介

识记题分值通常不高，但适合选择、判断、填空。

两种运行方式

  • 交互式：在 >>> 后逐句输入，立即得到结果。
  • 文件式：保存为 .py，整体运行；IDLE 中常用 F5。

模块导入

import random
random.randint(1, 10)

from random import randint
randint(1, 10)

写了别名就必须用别名：import random as rd 后调用 rd.random()。

语法框架与标识符

  • Python 用缩进表示代码块；同一层缩进必须一致。冒号后通常进入缩进块。
  • 标识符可含字母、数字、下划线；不能以数字开头，不能用关键字；大小写敏感。
  • 变量必须先赋值后使用；Python 是动态类型语言，变量可重新绑定不同类型对象。
  • 单行注释以 # 开头。三引号本质上是字符串字面量，不要把它机械地当作真正注释语法。
  • Python 没有原生 do...while 结构。

第 2 章　编写简单的程序

高频这里最容易出表达式结果、字符串、切片、类型转换和报错判断。

2.1 输入、类型转换与赋值

name = input("姓名：")        # 永远返回 str
age = int(input("年龄："))    # 先输入字符串，再转 int
x = float("3.13e3")           # 3130.0

a = b = c = 0                 # 链式赋值
a, b = 1, 2                   # 解包赋值
a, b = b, a                   # 交换
表达式结果原因
int("300")300合法整数字符串

float("3.13e3")3130.0科学计数法合法

"af" + 10TypeError字符串不能直接与整数相加

2.2 运算符与优先级

类别常用运算记忆点
算术+ - * / // % **/ 真除；// 整除；% 余数；** 乘方
比较== != > < >= <=可以链式比较：1 < x <= 10
逻辑not and or常用优先级：算术 > 比较 > not > and > or
成员in、not in字典上判断的是键
身份is、is not比较是否同一对象，不等同于 ==
必改错：“三位数且能被 9 整除”应写 100 <= x <= 999 and x % 9 == 0，不是 x // 9 == 0。

浮点数不宜直接依赖精确相等：abs(a-b) < 1e-9 更稳妥。

2.3 字符串：索引、切片、方法

索引与切片

s = "PYTHON"
s[0]       # 'P'
s[-1]      # 'N'
s[1:4]     # 'YTH'
s[::-1]    # 'NOHTYP'

切片规则：左闭右开，即包含起点、不包含终点。

不可变性

s = "abc"
print(s.upper())  # ABC
print(s)          # abc

# s[0] = "A" 会报 TypeError

字符串方法通常返回新字符串，必须接住返回值才能永久保留。

用途写法结果/注意
大小写s.lower()、s.upper()返回新字符串
查找s.index(x)、s.find(x)找不到时：index 报错，find 返回 -1
计数s.count(x)返回出现次数
拆分s.split(sep)返回列表；原字符串不变
替换s.replace(old,new)返回新字符串；原字符串不变
去两端字符s.strip()默认去两端空白，不删除中间空白
编码chr(97) / ord("b")'a' / 98
格式化"{:.2f}".format(3.14159)'3.14'

常用编码范围：数字 48-57，大写字母 65-90，小写字母 97-122。字符串逐字符按 Unicode 编码比较。

第 3 章　程序流程控制

高频选择、判断、填空、简答程序题都会出现。代码追踪时每轮都写变量表。

3.1 三种基本结构与分支

三种基本结构：顺序、选择、循环。选择结构有单分支、双分支、多分支。

score = int(input("成绩："))
if score >= 90:
    level = "A"
elif score >= 80:
    level = "B"
elif score >= 60:
    level = "C"
else:
    level = "D"

条件表达式：表达式1 if 条件 else 表达式2。例如每 4 个元素换行应使用：

for i, value in enumerate(data):
    print(value, end="\n" if (i + 1) % 4 == 0 else " ")

3.2 for、while、range

for 遍历循环

适合遍历序列/集合/字典或次数已知的循环。

for i in range(1, 6):
    print(i, end=" ")
# 1 2 3 4 5

while 条件循环

适合由条件控制、次数事先不确定的循环。

n = 5
while n > 0:
    print(n)
    n -= 1

range(start, stop, step) 同样左闭右开；step 不能为 0。

3.3 break、continue、循环 else

语句作用下一步去哪
break立即结束当前最内层循环跳到循环后；循环 else 不执行
continue跳过本轮剩余语句回循环头判断/取下一个元素
循环 else循环正常结束时执行若被 break 打断则不执行
for i in range(2, n):
    if n % i == 0:
        print("不是素数")
        break
else:
    print("是素数")

3.4 迭代、枚举与嵌套循环

  • 迭代三要素：初值、迭代关系式、终止条件。
  • 枚举法：把所有可能情况列出，再用条件筛选。
  • 嵌套循环总次数通常是各层次数的乘积；break 只跳出最内层。
# 统计英文句子中大写、小写、数字的数量
upper = lower = digit = 0
for ch in text:
    if ch.isupper():
        upper += 1
    elif ch.islower():
        lower += 1
    elif ch.isdigit():
        digit += 1

第 4 章　函数

应用题核心老师明确说可能直接要求设计函数，难度与实验接近或略低。

4.1 定义、调用与返回值

def cal_sum(start, end):
    total = 0
    for n in range(start, end + 1):
        total += n
    return total

answer = cal_sum(1, 100)
  • 函数调用前必须已经定义。
  • 函数可以没有 return，此时默认返回 None。
  • return a, b 实际返回元组，可用 x, y = func() 解包。
  • return 一执行，函数立刻结束。

4.2 参数规则

参数方式例子易错点
位置参数f(3,5,8)按顺序匹配
关键字参数f(3,height=5,length=8)关键字参数后不能再放普通位置参数；同一参数不能给两次
默认值参数def f(a,b=6,c=8)默认参数放在非默认参数后
可变位置参数def f(*args)收集为元组
可变关键字参数def f(**kwargs)收集为字典，且必须最后
def f(a, b=6, c=8):
    return a**2 + b + c

f(2, c=3)  # 13

4.3 局部变量、全局变量与 global

  • 函数内新赋值的变量通常是局部变量；同名时“局部优先”。
  • 只读取全局变量一般不需声明；要在函数内重新绑定全局变量，先写 global x。
  • 尽量用参数和返回值传递数据，少依赖全局变量。
x = 10
def change():
    global x
    x = 5
change()
print(x)  # 5

4.4 递归与 lambda

递归两要素

def fact(n):
    if n == 0:        # 递归出口
        return 1
    return n * fact(n-1)  # 递归步骤

必须能逐步靠近出口，否则无限递归。

lambda

sub = lambda x, y: x - y
sub(5, 15)  # -10

data.sort(key=lambda item: item[1])

只写一个表达式，没有显式 return，表达式结果就是返回值。

4.5 上机同级函数题清单

实验教程中反复出现：奇偶判断、素数、闰年、各位数字和、重复元素、列表统计、密码强度、成绩字典、递归数列。当前应用题最可能把其中一种简化后要求“定义函数 + 主程序调用”。

第 5 章　列表与元组

高频重点不只是记方法，还要分清“是否修改原对象”和“返回什么”。

5.1 列表方法与副作用

操作效果返回值/陷阱
ls.append(x)把 x 整体作为一个元素放末尾原地修改，返回 None
ls.extend(it)逐个加入可迭代对象中的元素原地修改，返回 None
ls.insert(i,x)在索引 i 前插入原地修改
ls.remove(x)删除第一个值为 x 的元素找不到报 ValueError
ls.pop(i)删除并返回索引 i 的元素缺省 i 时删末尾
del ls[a:b]按索引/切片删除del 不是方法
ls.sort()原地排序返回 None
sorted(ls)生成已排序新列表原列表不变
ls.index(x)首次出现的索引不存在报错
ls.count(x)出现次数不修改列表
a = [1, 2]
b = a.copy()
a.append([3, 4])   # [1, 2, [3, 4]]
b.extend([3, 4])   # [1, 2, 3, 4]

5.2 列表生成式

# 1 到 20 中偶数的平方
squares = [i**2 for i in range(1, 21) if i % 2 == 0]

阅读顺序：先看 for 的取值，再看 if 筛选，最后计算最左边表达式。

5.3 赋值、浅拷贝与深拷贝

写法新外层对象？内层对象共享？
b = a否，同一列表全部共享
b = a.copy() / a[:]是是，属于浅拷贝
b = copy.deepcopy(a)是递归复制，通常不共享
a = [3, 6, [4, 9]]
b = a.copy()
a[2][0] = 20
print(b)  # [3, 6, [20, 9]]，内层列表共享

5.4 元组

  • 元组本身不可变，但可包含列表等可变对象；可变对象内部仍能修改。
  • 单元素元组必须有逗号：(3,)；(3) 只是整数 3。
  • 元组支持索引、切片、in、count、index，不支持 append/remove。
  • 互转：list(t)、tuple(ls)。

第 6 章　字典与集合

6.1 字典

  • 字典是映射类型；键唯一且必须可哈希（通常用数字、字符串、元组），值可为任意类型。
  • x in d 判断的是键；for x in d 默认遍历键。
  • Python 3.7+ 字典保留插入顺序，但考试不应依赖旧题中“无序输出”的具体顺序。
counts = {}
for ch in text.lower():
    if ch.isalpha():
        counts[ch] = counts.get(ch, 0) + 1

for key, value in counts.items():
    print(key, value)
操作说明
d[key]访问；键不存在时抛 KeyError
d.get(key, default)不存在时返回默认值，不自动加入字典
d[key] = value添加新键或修改原键值
d.pop(key, default)删除并返回值；可提供默认值
d.update(other)合并/更新；字典不能用 +
d.keys()/values()/items()返回视图对象；items 中每项为二元组

6.2 集合

  • 集合无序、自动去重、元素唯一；集合本身可变，元素必须可哈希。
  • 空集合写 set()；{} 是空字典。
  • 集合不能作为另一个普通集合的元素；列表也不能作为集合元素。
运算写法含义
交集A & B同时属于 A、B
并集A | B属于 A 或 B
差集A - B属于 A 但不属于 B
对称差A ^ B只属于其中一个，不在交集

remove(x) 不存在会报错；discard(x) 不存在也不报错；add(x) 加一个元素，update(it) 加入多个元素。

第 7 章　文件与异常

高频简答最常考“文件类型、打开模式、三种读法、两种写法、异常执行顺序”。

7.1 文本文件与二进制文件

  • 文本文件：有字符编码，按字符串理解，常指定 encoding="utf-8"。
  • 二进制文件：按字节流处理，在模式中加 b，读写对象是 bytes。

7.2 打开模式速查

模式读/写不存在原内容初始位置
r只读报错保留开头
r+读写报错保留开头
w只写创建清空开头
w+读写创建清空开头
a追加写创建保留末尾
a+读写/追加创建保留写入固定在末尾
必须记准：open() 未写模式时默认是 'r'，不是 'r+'。
with open("data.txt", "r", encoding="utf-8") as f:
    content = f.read()
# 离开 with 后自动关闭

7.3 读、写、指针

方法返回/接收关键区别
read()全文字符串/字节read(n) 读 n 个字符或字节
readline()一行字符串通常保留行尾换行符
readlines()按行组成的列表每一行是一个字符串元素
write(s)一个字符串/字节对象不自动换行
writelines(seq)字符串序列不自动添加分隔符；元素含 \n 才换行

读完后文件指针在末尾；要重读可 f.seek(0)。追加模式写入仍在末尾。

7.4 CSV 与异常

CSV

  • csv.reader(f)：每行得到一个列表。
  • writer.writerow(row)：写一行。
  • writer.writerows(rows)：写多行。

异常执行顺序

try:
    x = int(text)
except ValueError:
    print("不是整数")
else:
    print("转换成功", x)
finally:
    print("总会执行")
  • try 中发生并被匹配的异常，转到相应 except。
  • 没有异常才执行 else。
  • finally 通常无论是否异常都执行。
  • 异常处理不能保证程序逻辑正确，只能处理预料到的异常。

程序阅读四步法

  1. 先标类型：字符串、列表、元组、字典、集合？可变还是不可变？
  2. 再画变量表：每轮循环写一行，只记录发生变化的变量。
  3. 检查边界：range 和切片的终点取不到；负步长方向是否合理；break 是否打断 else。
  4. 最后看输出：print 的 end、sep、格式化宽度、转义字符都要计入。

示例：同步赋值追踪

a, b = 1, 2
for i in range(3):
    a, b = b, b-a
    print(a, b)

# 第1轮：a=2,  b=1
# 第2轮：a=1,  b=-1
# 第3轮：a=-1, b=-2

a,b = b,b-a 会先把右侧旧值全部算完，再同时赋给左侧，不能按两条普通赋值逐条算。

常见报错定位

异常常见原因
SyntaxError语法不合法、冒号/括号缺失、参数顺序非法
IndentationError缩进层级或空格/Tab 不一致
NameError变量未定义、拼写错误、超出作用域
TypeError类型不支持该操作，如字符串 + 整数、列表作字典键
ValueError类型形式对但值内容不合要求，如 int("3.1")
IndexError列表/元组/字符串索引越界
KeyError直接访问不存在的字典键
FileNotFoundError用 r/r+ 打开不存在文件

简答题与应用题答题模板

概念简答：三句拿分法

  1. 先定义：它是什么。
  2. 再比较/规则：关键差别、适用条件、返回类型。
  3. 给一个微型例子：用一行代码或结果证明。
示例：说明 break 与 continue 的区别

break 立即结束当前最内层循环，循环后的语句继续执行，并使循环的 else 不执行；continue 只跳过本轮剩余语句，返回循环头继续下一轮。两者都只影响所在的最内层循环。

示例：说明 read、readline、readlines 的区别

read() 返回全部内容的字符串（可指定读取字符数）；readline() 返回当前一行字符串；readlines() 返回由各行字符串组成的列表。三者都会推进文件指针。

程序简答：五栏追踪法

答案至少写：①功能；②关键变量类型和作用；③循环/分支如何变化；④最终输出；⑤若有错，异常类型与最小修改。

应用题：10 分函数模板

def analyze_scores(scores):
    """返回平均分和高于平均分的列表。"""
    if not scores:
        return 0, []
    average = sum(scores) / len(scores)
    above = [x for x in scores if x > average]
    return average, above

data = [78, 92, 66, 85, 99]
avg, high = analyze_scores(data)
print("平均分：{:.2f}".format(avg))
print("高于平均分：", high)
