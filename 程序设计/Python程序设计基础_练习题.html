简答题参考要点
  1. for 用于遍历可迭代对象或次数较明确的循环；while 由条件控制。break 立即结束循环，continue 跳过本次剩余语句。
  2. 递归出口和递归步骤。出口负责终止；递归步骤必须让问题规模缩小并逐渐接近出口，否则会无限递归并触发错误。
  3. 相同：都是序列，支持索引、切片、遍历，可存放不同类型对象。不同：列表可变、有增删改方法，用方括号；元组不可变，通常用圆括号，单元素需逗号。
  4. 位置参数按顺序对应；关键字参数按名称对应；默认值参数可在调用时省略；*args 收集额外位置参数为元组；**kwargs 收集额外关键字参数为字典。
  5. r 只读，文件不存在报错；w 只写，不存在则创建，存在则清空；a 追加写，不存在则创建，原内容保留且写入位于末尾。
应用题 1 参考程序
scores = list(map(int, input().split()))
levels = {'A': 0, 'B': 0, 'C': 0, 'D': 0, 'F': 0}

for s in scores:
    if s >= 90:
        levels['A'] += 1
    elif s >= 80:
        levels['B'] += 1
    elif s >= 70:
        levels['C'] += 1
    elif s >= 60:
        levels['D'] += 1
    else:
        levels['F'] += 1

print(f"平均分：{sum(scores)/len(scores):.2f}")
print("最高分：", max(scores), sep="")
print("最低分：", min(scores), sep="")
print("及格人数：", sum(s >= 60 for s in scores), sep="")
print("等级统计：", levels, sep="")

应用题 2 参考程序
import csv

counts = {}
try:
    with open("data.txt", "r", encoding="utf-8") as f:
        for line in f:
            for word in line.lower().split():
                counts[word] = counts.get(word, 0) + 1
except FileNotFoundError:
    print("data.txt 不存在")
else:
    with open("result.csv", "w", encoding="utf-8", newline="") as f:
        writer = csv.writer(f)
        for word in sorted(counts):
            writer.writerow([word, counts[word]])
    print("统计完成")

评分点：文件读取与 with 2 分；忽略大小写和分词 2 分；字典计数 2 分；排序及 CSV 写入 3 分；异常处理 1 分。
